Herramientas ADB

Android Debug Bridge (ADB) y Fastboot son herramientas oficiales de la plataforma Android que permiten comunicarse con un dispositivo desde un ordenador. ADB se utiliza principalmente con Android iniciado; Fastboot trabaja desde el modo bootloader o fastboot.

Son habituales para desarrollo, diagnóstico, mantenimiento e instalación de software en dispositivos propios o autorizados.

ADB y Fastboot: diferencias

ADB (Android Debug Bridge)

Establece una conexión entre el ordenador y Android mediante el servicio de depuración. Permite ejecutar comandos en una shell remota, transferir archivos, instalar paquetes y consultar registros del sistema.

Fastboot

Es una herramienta de bajo nivel que se comunica con el bootloader. Se utiliza para consultar el estado del dispositivo y, cuando el fabricante lo permite, gestionar particiones o instalar imágenes del sistema.

Requisitos y preparación

  • Instalar Android SDK Platform-Tools desde la documentación oficial de Android.
  • Activar las Opciones de desarrollador y la Depuración USB si se va a utilizar ADB por cable.
  • Conectar el dispositivo y aceptar en su pantalla la huella RSA del ordenador. No autorizar equipos que no sean de confianza.
  • Para Fastboot, reiniciar al modo bootloader mediante el método específico del fabricante.

Importante: desbloquear el bootloader suele borrar todos los datos del dispositivo y puede afectar a la garantía o a funciones de seguridad. El procedimiento depende del fabricante y del modelo.

Comandos básicos de ADB

Comprobar la conexión

adb devices

Muestra los dispositivos detectados y su estado. Si aparece como unauthorized, hay que aceptar la autorización en el teléfono.

Acceder a la shell

adb shell

Abre una terminal dentro del dispositivo con los permisos del usuario de depuración; no concede acceso root automáticamente.

Instalar y transferir archivos

adb install aplicacion.apk
adb push archivo.txt /sdcard/Download/
adb pull /sdcard/Download/archivo.txt .

Instala un APK o copia archivos entre el ordenador y el almacenamiento accesible del dispositivo.

Consultar registros y reiniciar

adb logcat
adb reboot
adb reboot bootloader

logcat muestra registros del sistema y de las aplicaciones. Los registros pueden contener datos privados; revísalos antes de compartirlos.

Comandos básicos de Fastboot

fastboot devices
fastboot getvar product
fastboot reboot

Permiten comprobar si el dispositivo está detectado, consultar una variable de identificación y reiniciar Android. La disponibilidad de variables puede variar según el bootloader.

No ejecutes comandos de escritura como flash, erase o el desbloqueo del bootloader sin confirmar antes que la imagen corresponde exactamente al modelo y variante del dispositivo. Un archivo incorrecto puede dejarlo inutilizable.

Comprobación de la instalación

adb version
fastboot --version
which adb
which fastboot

Las herramientas deben mostrar su versión y el sistema debe localizar sus ejecutables. Para comprobar la conexión real, utiliza adb devices con Android iniciado o fastboot devices en el modo correspondiente.
