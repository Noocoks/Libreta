Hydra

Herramienta de auditoría de autenticación para entornos autorizados.

pentesting credenciales diccionario ssh ftp

Hydra (THC Hydra) es una herramienta de código abierto que automatiza pruebas de autenticación contra distintos servicios de red mediante módulos específicos. En auditorías autorizadas se utiliza para evaluar la resistencia de las credenciales y de los controles de acceso.

Hydra no descubre por sí sola una vulnerabilidad del software: prueba credenciales a través de mecanismos de inicio de sesión y depende de la respuesta del servicio, de la configuración y de los límites que este aplique.

Casos de uso

Auditoría de autenticación

Comprobar, dentro de un alcance aprobado, si las cuentas de prueba utilizan contraseñas previsibles y si las políticas de acceso están correctamente configuradas.

Evaluación de controles defensivos

Observar si el servicio aplica limitación de intentos, retardos, alertas o bloqueos y comprobar que estas medidas no impiden el acceso legítimo de forma desproporcionada.

Formación y laboratorio

Comprender cómo se comporta un servicio de autenticación ante intentos repetidos y relacionar los eventos observados con los registros del sistema.

Instalación

En distribuciones basadas en Debian, Ubuntu o Kali puede instalarse desde los repositorios configurados: 

                                          sudo apt update
                                          sudo apt install hydra

Comprobación 

                                          command -v hydra
                                          hydra -h
                                          hydra -U ssh

El primer comando localiza el ejecutable, el segundo muestra la ayuda general y el tercero consulta la información del módulo SSH. La disponibilidad de módulos puede variar según la compilación.

Antes de una prueba: define por escrito el sistema autorizado, las cuentas de laboratorio, el volumen máximo de solicitudes y la ventana de ejecución. Evita cuentas reales y detén la actividad si aparecen bloqueos inesperados o degradación del servicio.
