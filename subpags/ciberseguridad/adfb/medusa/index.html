Medusa

Herramienta de auditoría de autenticación para entornos autorizados.

Medusa es una herramienta Open Source que permite evaluar la seguridad de servicios de red mediante pruebas automatizadas de autenticación. Se utiliza para comprobar la fortaleza de las credenciales y las políticas de acceso en sistemas propios o autorizados.

Casos de uso

Auditorías de seguridad

Detectar credenciales débiles y comprobar las políticas de autenticación.

Laboratorios y formación

Estudiar los mecanismos de autenticación y las buenas prácticas de seguridad en entornos controlados.

Validación de políticas

Comprobar medidas como el bloqueo de cuentas, la autenticación multifactor y la limitación de intentos.

Instalación

sudo apt update
sudo apt install medusa

Comprobación

which medusa
medusa -V
medusa -h

Si los comandos responden correctamente, la herramienta está instalada y disponible.
