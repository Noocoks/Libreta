ExifTool

ExifTool es una utilidad de línea de comandos que permite leer, escribir y modificar metadatos de numerosos formatos de imagen, audio, vídeo y documentos. Los metadatos son datos descriptivos incrustados en un archivo, distintos del contenido visual o textual que normalmente vemos.

En OSINT y análisis forense puede ayudar a examinar fechas, modelo de cámara, software utilizado o coordenadas GPS, siempre que esos campos estén presentes y sean fiables.

¿Qué información puede contener?

  • Datos técnicos: formato, dimensiones, orientación, códec o perfil de color.
  • Fechas: fecha de captura, modificación o creación, que pueden diferir entre sí.
  • Dispositivo y software: fabricante, modelo de cámara o aplicación que procesó el archivo.
  • Ubicación: coordenadas GPS, si el dispositivo o aplicación las guardó.
  • Autoría: autor, copyright, descripción y otros campos añadidos por el usuario.

Casos de uso

  • Inspeccionar metadatos antes de incorporar una imagen a una investigación.
  • Comprobar si un archivo contiene información de ubicación o datos personales.
  • Comparar metadatos de varios archivos como parte de un análisis, sin asumir que prueban por sí solos su origen.
  • Eliminar o normalizar metadatos antes de publicar archivos, tras conservar una copia original.
  • Exportar campos a CSV para organizar conjuntos de evidencias.

Instalación y primera comprobación

En Debian, Ubuntu y Kali, el paquete habitual se encuentra en los repositorios:

sudo apt update
sudo apt install libimage-exiftool-perl
exiftool -ver
exiftool imagen.jpg

El último comando muestra los metadatos que ExifTool puede leer del archivo indicado. Si un campo no aparece, puede que no exista, no sea compatible o haya sido eliminado.

Precauciones al editar

Las operaciones de escritura pueden alterar el archivo. Trabaja sobre una copia y conserva el original cuando tenga valor probatorio. Eliminar metadatos no garantiza anonimato: el propio contenido puede revelar información y algunos formatos conservan datos en estructuras distintas.
