Holehe

OSINTcorreocuentasprivacidad

Holehe comprueba si una dirección de correo parece estar asociada a cuentas en servicios online compatibles. Automatiza consultas a mecanismos de registro o recuperación y analiza las respuestas.

Sus resultados son indicios, no una prueba de identidad ni de control de una cuenta. Los proveedores pueden modificar sus respuestas, limitar consultas o utilizar mensajes ambiguos para proteger a sus usuarios.


Qué hace y qué no hace

Holehe intenta inferir si un servicio reconoce una dirección. No accede a la cuenta, no obtiene contraseñas y no demuestra quién la controla.


Funcionamiento general

  1. Recibe una dirección de correo autorizada.
  2. Selecciona módulos compatibles con los servicios que conoce.
  3. Consulta mecanismos públicos de registro o recuperación.
  4. Analiza respuestas HTTP, mensajes y otras señales.
  5. Clasifica cada resultado, incluyendo estados inciertos o limitados.

Casos de uso legítimos

  • Revisar la exposición de una dirección propia.
  • Auditar direcciones de prueba con autorización.
  • Estudiar el riesgo de enumeración de cuentas.
  • Comprender cómo los servicios protegen la privacidad de sus usuarios.

Instalación aislada

Utiliza un entorno virtual para no modificar el Python del sistema:

sudo apt update
sudo apt install python3 python3-venv python3-pip
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install holehe
holehe --help

La disponibilidad del paquete y sus dependencias puede cambiar. Si falla, consulta las instrucciones del repositorio y la versión de Python compatible.


Ejemplo con una dirección propia

holehe correo-de-prueba@example.com

Utiliza solo direcciones que controles o para las que tengas permiso expreso. Evita consultas masivas de direcciones de terceros.


Interpretación de resultados

  • Found: existe una señal compatible con una cuenta.
  • Not found: no se obtuvo señal; no demuestra que nunca haya existido una cuenta.
  • Rate limited: el servicio limitó la consulta; no es un resultado negativo.
  • Uncertain / error: la evidencia no permite clasificar el resultado.

Limitaciones y privacidad

  • Los formularios y respuestas de los proveedores cambian.
  • Los controles antiabuso pueden limitar o falsear la señal observable.
  • Una cuenta asociada a un correo no identifica a una persona concreta.
  • Los datos de recuperación parcialmente ocultos también pueden ser información personal.

Uso responsable: limita las consultas a direcciones propias o autorizadas, no publiques resultados identificables y elimina los datos cuando dejen de ser necesarios.
