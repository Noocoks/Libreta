Arquitectura - GoPhish

GoPhish reúne una interfaz de administración y componentes que preparan campañas, entregan mensajes por SMTP, sirven páginas y registran interacciones. La configuración de red y el almacenamiento deben protegerse como parte del laboratorio.

Componentes

Interfaz administrativa

Permite gestionar usuarios, grupos, plantillas, páginas, perfiles y campañas. Debe estar accesible solo para administradores autorizados.

Grupos

Organizan destinatarios de la simulación. En este laboratorio deben contener direcciones ficticias o cuentas controladas.

Plantillas y páginas

Definen el correo y el destino del enlace. Para formación utiliza una página educativa y no recojas contraseñas reales.

Perfil SMTP

Define host y puerto de entrega. En un laboratorio local debe apuntar a MailHog y no a un servidor externo.

Seguimiento

Registra eventos de envío, apertura y clic. Las herramientas de privacidad y seguridad pueden alterar estas métricas.


Separación de red

  • Consola administrativa en localhost o red de gestión aislada.
  • SMTP de pruebas sin relay hacia Internet.
  • Landing page disponible solo para navegadores de prueba.
  • Base de datos y exportaciones con permisos restrictivos.
