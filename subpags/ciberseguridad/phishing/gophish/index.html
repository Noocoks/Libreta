GoPhish es una plataforma de código abierto para organizar simulaciones de phishing y ejercicios de concienciación. Gestiona grupos de destinatarios, plantillas, páginas educativas, perfiles SMTP y resultados.

Su uso requiere autorización, alcance definido y responsables identificados. Esta documentación se centra en laboratorios y formación, no en la captura de credenciales reales ni en campañas contra terceros.

Qué permite evaluar

  • Reconocimiento de señales sospechosas en un mensaje simulado.
  • Interacción con enlaces de prueba.
  • Uso de los canales internos para reportar mensajes.
  • Funcionamiento de controles técnicos y procesos de respuesta.

Elementos de una campaña

  1. Grupo: destinatarios incluidos en el alcance autorizado.
  2. Plantilla: contenido del mensaje de simulación.
  3. Landing page: página educativa que recibe al usuario tras el enlace.
  4. Sending profile: configuración SMTP que entrega el mensaje.
  5. Campaign: relaciona plantilla, página, grupo, URL y perfil.
  6. Results: eventos y métricas obtenidos durante el ejercicio.

Métricas e interpretación

  • Enviado: el sistema procesó el envío mediante el perfil configurado.
  • Abierto: puede depender de imágenes de seguimiento que algunos clientes bloquean o precargan.
  • Clic: registra visitas al enlace; proxies y sistemas de seguridad pueden abrirlo automáticamente.
  • Datos enviados: no se deben solicitar ni almacenar contraseñas reales en un ejercicio formativo.
  • Reportado: requiere un canal complementario de reporte definido por la organización.

Una apertura o un clic no demuestran por sí solos una decisión consciente del usuario. Analiza varias señales y prioriza métricas agregadas.

Flujo de trabajo recomendado

  1. Define objetivo, alcance, periodo y responsables.
  2. Usa destinatarios de prueba y correo local.
  3. Prepara un mensaje inocuo y una página educativa.
  4. Configura el SMTP para apuntar a MailHog.
  5. Envía primero un mensaje a una dirección controlada.
  6. Revisa eventos y documenta limitaciones.
  7. Comparte conclusiones agregadas y recomendaciones.

Seguridad

  • No recojas contraseñas ni credenciales reales.
  • No expongas la consola administrativa a Internet.
  • Protege la base de datos y limita el acceso a resultados.
  • Utiliza SMTP de laboratorio para evitar envíos accidentales.
  • Define retención y eliminación de datos antes de comenzar.
