Cortafuegos y privacidad de red

Portmaster

Cortafuegos de aplicaciones y monitorización de conexiones para Windows y GNU/Linux. Permite observar qué aplicaciones se comunican, aplicar reglas por proceso y bloquear dominios de seguimiento a nivel DNS.

Público objetivo: usuarios avanzados y administradores que necesitan controlar el tráfico de red de sus equipos

Plataformas: Windows y distribuciones GNU/Linux compatibles

Qué es y cómo funciona

Portmaster es una suite de privacidad y cortafuegos de aplicaciones desarrollada por Safing. Intercepta conexiones a nivel de pila de red y asocia los flujos con los procesos que los generan. En Windows utiliza Windows Filtering Platform (WFP) y un controlador de kernel; en Linux integra reglas mediante nfqueue y obtiene información de procesos con mecanismos del sistema como eBPF y /proc.

La interfaz presenta las conexiones por aplicación y permite definir reglas globales o específicas. También puede bloquear dominios de anuncios, rastreadores y malware mediante listas DNS. La actividad base se procesa localmente; las funciones de SPN utilizan infraestructura externa.

Funciones principales

  • Monitorización de conexiones entrantes y salientes por aplicación
  • Reglas de permitir/bloquear por aplicación, dominio, país o tipo de conexión
  • Bloqueo DNS de rastreadores, anuncios y dominios maliciosos
  • DNS cifrado mediante DNS-over-HTTPS o DNS-over-TLS
  • Historial y análisis de actividad de red, con funciones avanzadas de pago
  • SPN (Safing Privacy Network), servicio opcional de privacidad con suscripción

Instalación y configuración

Descarga el instalador desde la web oficial de Safing o desde el repositorio oficial. En Windows, el componente de red utiliza WFP; en Linux, la instalación configura reglas y permisos de red propios de la distribución. Revisa la guía específica de tu sistema y conserva acceso local al equipo durante la primera configuración.

Empieza en modo de monitorización para observar las conexiones habituales. Crea reglas específicas para aplicaciones que conozcas y evita bloquear servicios del sistema por nombre sin comprobar su función. Exporta o documenta las reglas antes de realizar cambios importantes.

Licencia y distribución

Portmaster es gratuito y de código abierto. Algunas funciones avanzadas, como SPN y determinados informes de actividad o ancho de banda, se ofrecen como servicios de pago. La licencia del código y las condiciones de cada servicio son independientes.

Seguridad, privacidad y limitaciones

Portmaster interviene en la pila de red y utiliza componentes de bajo nivel; una regla incorrecta puede cortar la conectividad de una aplicación o del propio sistema. Mantén un método de recuperación y evita modificar reglas críticas en una sesión remota sin acceso alternativo.

Puede coexistir con el Firewall de Windows, pero otros cortafuegos, VPN y filtros de red pueden generar conflictos o rutas inesperadas. Cambia una configuración cada vez y verifica DNS, conectividad y resolución de nombres tras cada ajuste.

El proyecto declara que la actividad base se procesa localmente, salvo el servicio SPN. Revisa la política de privacidad y las condiciones de las funciones conectadas antes de activarlas.
