API

Una API (Application Programming Interface) define las operaciones, estructuras de datos y reglas mediante las que un componente de software ofrece capacidades a otros componentes.

Concepto y contexto

Una API no es necesariamente una conexión de red. Puede ser una interfaz de biblioteca dentro del mismo proceso, una API del sistema operativo o una interfaz remota expuesta mediante HTTP. La especificación delimita qué operaciones están disponibles y qué entradas, salidas y errores se esperan.

Funcionamiento técnico

En una API HTTP, el cliente construye una petición a un recurso o endpoint, envía un método y, cuando corresponde, una representación de datos. El servidor valida la petición, ejecuta la operación y devuelve un código de estado y una respuesta. La autenticación y autorización se aplican según el diseño del servicio.

Consideraciones prácticas y seguridad

Revisa la versión de la API, el esquema de datos, límites de uso, autenticación, política de errores y compatibilidad hacia atrás. Nunca publiques claves o tokens en código cliente ni repositorios.

Artículo técnico de consulta. Comprueba siempre la documentación oficial de la plataforma y la versión concreta que estés utilizando.
