BIOS y UEFI

BIOS y UEFI son firmware de plataforma que prepara el equipo para iniciar un sistema operativo. UEFI es la especificación moderna y no debe confundirse con el BIOS heredado.

Concepto y contexto

Durante el encendido, el firmware inicializa componentes esenciales, ejecuta comprobaciones y selecciona un dispositivo o entrada de arranque. En equipos UEFI, el firmware puede cargar una aplicación EFI desde la partición del sistema EFI (ESP), normalmente en un disco con tabla GPT.

Funcionamiento técnico

UEFI define servicios de arranque y variables persistentes, admite controladores EFI y puede aplicar Secure Boot para verificar firmas de componentes de arranque. El modo CSM/Legacy permite compatibilidad con arranque BIOS antiguo, pero puede cambiar los requisitos de particionado y arranque.

Consideraciones prácticas y seguridad

Antes de cambiar opciones como Secure Boot, TPM, CSM o modo SATA, registra la configuración original y comprueba el método de arranque de Windows/Linux. Cambiarlo sin preparar el sistema puede impedir el arranque o activar recuperación de cifrado.

Artículo técnico de consulta. Comprueba siempre la documentación oficial de la plataforma y la versión concreta que estés utilizando.
