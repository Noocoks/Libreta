LIBRETA / DICCIONARIO TÉCNICO

Contenedores

Un contenedor es un proceso o conjunto de procesos aislados mediante funciones del sistema operativo. Comparte el kernel del anfitrión, a diferencia de una máquina virtual tradicional que ejecuta su propio kernel invitado.

Concepto y contexto

En Linux, los namespaces ofrecen vistas aisladas de recursos como procesos, red, montajes, IPC, usuarios y hostname. Los cgroups organizan procesos y permiten contabilizar o limitar consumo de CPU, memoria y E/S. Las capacidades Linux, seccomp y perfiles LSM pueden reducir privilegios.

Funcionamiento técnico

Una imagen suele componerse de capas de solo lectura y una capa escribible al crear el contenedor. Los volúmenes mantienen datos fuera del ciclo de vida del contenedor; las redes virtuales permiten conectar servicios. Un runtime como containerd o CRI-O gestiona el ciclo de ejecución; Docker Engine integra herramientas de construcción y administración.

Consideraciones prácticas y seguridad

Los contenedores no son una frontera de seguridad absoluta. Evita ejecutar como root sin necesidad, montar el socket del motor, usar privileged, compartir el host PID/network o introducir secretos en la imagen. Fija versiones y analiza imágenes.

Artículo técnico de consulta. Comprueba siempre la documentación oficial de la plataforma y la versión concreta que estés utilizando.
