Anthropic & Claude

claude-code claude llm api python-sdk razonamiento

Anthropic desarrolla la familia de modelos Claude y ofrece una API para integrarlos en aplicaciones. Desde Python, el SDK oficial gestiona la petición, la autenticación y la lectura de la respuesta.

Claude puede utilizarse desde diferentes productos e interfaces. Esta página documenta el acceso mediante API, que requiere una credencial propia y está sujeto a los límites y condiciones del proyecto configurado en la consola.


Conceptos principales

  • Anthropic: proveedor del servicio y de la API.
  • Claude: familia de modelos que procesa las entradas.
  • API key: credencial utilizada para autenticar la petición.
  • Messages API: endpoint de conversación que recibe mensajes y devuelve contenido generado.
  • SDK: biblioteca oficial que facilita el uso de la API desde Python.

Preparar el entorno

Activa el entorno virtual descrito en la guía del proyecto local e instala el paquete oficial: 

pip install --upgrade anthropic

Mantener el SDK actualizado ayuda a utilizar los métodos y parámetros compatibles con la versión actual de la API.


Autenticación

Guarda la clave en el archivo .env:

ANTHROPIC_API_KEY=tu_clave

Carga la variable de entorno antes de inicializar el cliente. Evita incluir el valor literal en el código, en capturas o en repositorios compartidos.

Si la autenticación falla, revisa que la clave esté activa, que se haya cargado en el proceso y que pertenezca a la cuenta o espacio de trabajo esperado.


Crear y ejecutar la prueba

La libreta contiene un script de comprobación independiente:

python test_claude.py
  • Archivo: Comprobante Anthropic.
  • Objetivo: validar la carga de la clave y realizar una petición de prueba.
  • Resultado esperado: recibir y mostrar contenido devuelto por la API.

Errores habituales

  • 401 / autenticación: clave incorrecta, ausente o revocada.
  • 429 / límite: se ha alcanzado un límite de velocidad o uso; consulta la respuesta y la consola.
  • Modelo no disponible: el identificador puede haber cambiado o no estar habilitado para la cuenta.
  • 400 / petición inválida: revisa el formato de los mensajes y los parámetros obligatorios.
  • Respuesta inesperada: comprueba el tipo de bloque devuelto antes de acceder a su contenido.

Consulta el catálogo vigente antes de cambiar el identificador de modelo en un script: los nombres y las capacidades evolucionan.
