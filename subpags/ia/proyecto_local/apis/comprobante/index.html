Este script comprueba que las claves API almacenadas en .env se cargan correctamente. Por seguridad, muestra únicamente si están configuradas; nunca imprime sus valores.

Código

📄 check_apis.py
Python
 
import os
from dotenv import load_dotenv

load_dotenv()

for name in ("OPENAI_API_KEY", "ANTHROPIC_API_KEY"):
    configured = bool(os.getenv(name))
    status = "configurada" if configured else "no encontrada"
    print(f"{name}: {status}")

Resultado esperado

OPENAI_API_KEY: configurada
ANTHROPIC_API_KEY: configurada

Si aparece no encontrada, revisa la ubicación del archivo .env y el nombre de la variable.
