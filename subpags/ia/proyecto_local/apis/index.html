APIs

http api-key autenticación variables-entorno integración

Una API permite que un programa se comunique con un servicio externo mediante peticiones definidas. En este proyecto, los scripts Python utilizan las APIs de OpenAI y Anthropic para enviar entradas y recibir respuestas de sus modelos.

Para autorizar esas peticiones, cada proveedor entrega una clave API. La clave identifica el proyecto o cuenta que realiza la solicitud y debe mantenerse privada.


Obtener las claves

Accede a la consola oficial de cada proveedor, inicia sesión y crea una clave desde el apartado correspondiente:

  • OpenAI · gestión de claves API
  • Anthropic · gestión de claves API

Copia la clave cuando se muestre y guárdala en un lugar seguro. Si se expone, revócala desde la consola y genera otra.


Crear el archivo .env

Dentro de la carpeta raíz del proyecto, crea un archivo llamado .env: 

nano .env

Utiliza una variable distinta para cada proveedor:

OPENAI_API_KEY=tu_clave_de_openai
ANTHROPIC_API_KEY=tu_clave_de_anthropic

Los nombres deben coincidir con los que consulta el script mediante os.getenv(). No añadas comillas ni espacios alrededor del signo = salvo que la biblioteca o el formato lo requieran.


Cargar las variables desde Python

Instala python-dotenv y carga el archivo al inicio del programa: 

pip install python-dotenv
import os
from dotenv import load_dotenv

load_dotenv()

openai_key = os.getenv("OPENAI_API_KEY")
anthropic_key = os.getenv("ANTHROPIC_API_KEY")

load_dotenv() lee el archivo y añade sus valores al entorno del proceso. os.getenv() obtiene cada variable; si no existe, devuelve None, por lo que el programa debe comprobarla antes de inicializar el cliente.


Proteger los secretos

En Linux, limita los permisos del archivo:

chmod 600 .env

Añade el archivo y los artefactos del entorno virtual a .gitignore: 

.env
venv/
__pycache__/
*.pyc
  • No publiques claves en GitHub, incluso si el repositorio es privado.
  • No incluyas claves en capturas, documentación o registros de depuración.
  • No compartas una misma clave entre proyectos si puedes separarlas.
  • Revoca y sustituye cualquier clave que sospeches que se ha filtrado.
  • Revisa límites de uso, permisos y facturación desde la consola oficial.

Comprobar la configuración

La existencia de una variable no demuestra que la clave sea válida. La comprobación real consiste en realizar una petición sencilla con el SDK del proveedor y revisar la respuesta.

  • Comprobación de APIs
  • Configuración OpenAI
  • Configuración Anthropic

Nota sobre costes: las peticiones API pueden generar cargos independientes de las suscripciones de las aplicaciones web. Consulta los precios, límites y condiciones actuales de cada proveedor antes de realizar pruebas.
