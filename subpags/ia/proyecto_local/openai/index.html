OpenAI & S-GPT

shell-gpt llm api python-sdk chatbot

OpenAI desarrolla modelos y servicios de inteligencia artificial. Esta sección se centra en el acceso programático mediante la API: un script Python envía una petición autenticada y recibe una respuesta generada por el modelo solicitado.

La API es una interfaz para integrar los modelos en aplicaciones. No debe confundirse con la interfaz web de ChatGPT: son productos relacionados, pero tienen paneles, credenciales y condiciones de uso que deben consultarse por separado.


Conceptos principales

  • API: interfaz HTTP que permite a un programa solicitar operaciones al servicio.
  • Clave API: credencial que identifica y autoriza el proyecto que realiza la petición.
  • SDK: biblioteca que simplifica la comunicación con la API desde un lenguaje, en este caso Python.
  • Modelo: sistema seleccionado para procesar la entrada. Los identificadores disponibles pueden cambiar con el tiempo.
  • Respuesta: resultado devuelto por la API, junto con metadatos como uso y estado de la petición.

Preparar el entorno

Activa el entorno virtual creado en la guía del proyecto local e instala el SDK oficial: 

pip install --upgrade openai

El paquete se instala desde Python Package Index y permite utilizar los métodos documentados por OpenAI sin construir manualmente cada petición HTTP.


Autenticación

Genera una clave en el panel de la plataforma y guárdala en el archivo .env del proyecto: 

OPENAI_API_KEY=tu_clave

Carga la variable con python-dotenv y crea el cliente utilizando la variable de entorno. No escribas la clave literal dentro del script.

Si la petición devuelve un error de autenticación, comprueba que la variable existe en el proceso, que la clave pertenece al proyecto correcto y que no ha sido revocada.


Crear y ejecutar la prueba

La documentación de esta libreta incluye un script de comprobación independiente:

python test_openai.py
  • Archivo: Comprobante OpenAI.
  • Objetivo: verificar que Python encuentra la clave, conecta con el servicio y puede procesar una petición.
  • Resultado esperado: una respuesta válida del modelo configurado, no una ejecución completamente local.

Errores habituales

  • 401 / autenticación: clave incorrecta, ausente, revocada o asociada a otro proyecto.
  • 429 / límite: límite de uso, cuota o velocidad; revisa el panel y la respuesta de la API.
  • Modelo no disponible: identificador incorrecto, retirado o sin acceso para el proyecto.
  • Error de conexión: revisa DNS, conexión a Internet, proxy y certificados del sistema.
  • Respuesta vacía o inesperada: inspecciona el objeto devuelto y adapta el código a la estructura vigente del SDK.

Los nombres de modelos, parámetros y métodos pueden cambiar. Utiliza la referencia oficial como fuente de verdad en lugar de copiar un identificador antiguo de un ejemplo.


Shell-GPT desde terminal

Shell-GPT (comando sgpt) es una herramienta de línea de comandos que permite consultar modelos desde el terminal y generar explicaciones, fragmentos de código o sugerencias de comandos. Es independiente del script Python de esta página, aunque puede utilizar el mismo proveedor de API. 

pip install shell-gpt
sgpt "Explica qué hace este comando de Linux"

La instalación inicial puede solicitar una clave y guardar su configuración en el directorio de usuario de Shell-GPT. No des por hecho que utilizará automáticamente el archivo .env del proyecto. Comprueba la configuración oficial antes de cambiar credenciales o proveedores.
