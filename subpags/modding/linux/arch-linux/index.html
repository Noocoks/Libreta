Arch Linux

Distribución independiente de propósito general que parte de una base mínima y deja al usuario construir el sistema que necesita.

Filosofía y modelo

Arch prioriza simplicidad, minimalismo y cercanía al software original. La instalación base es deliberadamente pequeña: el usuario selecciona el entorno de escritorio, servicios, controladores y aplicaciones. No existe una edición estándar con un escritorio obligatorio.

  • Modelo: rolling release; las actualizaciones se reciben de forma continua.
  • Paquetes: Pacman para los repositorios oficiales.
  • AUR: repositorio comunitario de recetas de compilación; no equivale a un repositorio oficial auditado por Arch.
  • Documentación: ArchWiki es una referencia técnica central.

Instalación y mantenimiento

Arch requiere más intervención que una distribución de escritorio preconfigurada. El instalador guiado archinstall puede facilitar el proceso, pero es importante comprender particiones, UEFI, gestor de arranque, red, usuarios, audio, gráficos y entorno de escritorio.

En un sistema rolling release, realiza actualizaciones completas y consulta las noticias del proyecto cuando haya cambios relevantes. Evita actualizaciones parciales y conserva un medio de recuperación. Antes de instalar paquetes desde AUR, revisa su receta de compilación y los cambios que ejecutará.

BlackArch y Arch

BlackArch es un proyecto especializado basado en Arch, con un repositorio de herramientas de seguridad que puede integrarse en una instalación Arch existente. No forma parte de los repositorios oficiales de Arch ni es necesario para utilizar Arch como sistema generalista. Su documentación se recoge en una ficha independiente.

La incorporación de repositorios de terceros amplía la superficie de confianza y puede introducir conflictos; evalúa su necesidad antes de añadirlos.
