CatchyOS

Distribución GNU/Linux basada en Arch Linux, orientada a ofrecer una experiencia de escritorio preparada para el uso diario con herramientas propias y opciones de instalación guiadas.

Enfoque del proyecto

CatchyOS utiliza la base y el modelo rolling release de Arch, pero añade decisiones propias de instalación, selección de paquetes, configuración y mantenimiento. Su objetivo es facilitar el acceso a un entorno Arch-based sin exigir que el usuario construya absolutamente todos los componentes desde una instalación mínima.

  • Base: Arch Linux.
  • Actualizaciones: rolling release; el sistema recibe paquetes de forma continua.
  • Escritorios: ofrece distintas opciones de entorno gráfico según la imagen y el instalador vigente.
  • Herramientas: incluye utilidades y configuraciones mantenidas por el propio proyecto.

Instalación y mantenimiento

Antes de instalar, revisa los requisitos de hardware, el método de particionado y las opciones de escritorio publicadas para la versión actual. Prueba compatibilidad de GPU, Wi-Fi, Bluetooth y suspensión. Realiza una copia de seguridad y conserva un medio de recuperación.

Al seguir un modelo rolling release, es importante mantener el sistema actualizado, leer los avisos del proyecto y evitar mezclar repositorios de Arch, CachyOS y CatchyOS sin comprobar compatibilidad. No asumas que los procedimientos de Arch se aplican sin cambios a las herramientas propias de CatchyOS.

¿Para quién puede tener sentido?

Puede interesar a quien busca una distribución basada en Arch con una instalación más guiada y ajustes de escritorio ya preparados. Si quieres aprender cómo se construye Arch desde una base mínima, instala Arch directamente; si priorizas un ciclo conservador, considera una distribución de versiones fijas.
