Debian GNU/Linux

Distribución libre mantenida por una comunidad internacional. Debian es un sistema de propósito general y una de las bases más influyentes del ecosistema GNU/Linux.

Filosofía y ramas

Debian prioriza el software libre, la estabilidad y un proceso comunitario de desarrollo. Publica distintas ramas que responden a necesidades diferentes:

  • Stable: rama recomendada para la mayoría de instalaciones que priorizan estabilidad y mantenimiento.
  • Testing: paquetes que se preparan para una futura versión estable; no equivale a una rama estable.
  • Unstable (Sid): rama de desarrollo continuo, destinada a quienes aceptan cambios frecuentes y mayor intervención.

Gestión de paquetes y usos

Debian utiliza paquetes DEB y APT. Puede instalarse en equipos de escritorio, servidores y distintas arquitecturas. Su base estable también sirve como fundamento para otros proyectos, entre ellos Ubuntu y Parrot OS, aunque cada distribución derivada mantiene decisiones y repositorios propios.

Instalación y mantenimiento

  1. Descarga la imagen desde Debian y verifica su autenticidad.
  2. Selecciona la imagen adecuada para tu arquitectura y método de instalación.
  3. Comprueba soporte de firmware, Wi-Fi y gráficos para el hardware concreto.
  4. Planifica particiones y copias de seguridad antes de instalar.
  5. Configura repositorios según la documentación oficial y aplica actualizaciones de seguridad.

En servidores, revisa cuidadosamente los servicios expuestos, las políticas de actualización y las copias de seguridad.
