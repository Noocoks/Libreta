Fedora Linux

Distribución comunitaria patrocinada por Red Hat, con foco en software libre, tecnologías actuales y distintas ediciones para escritorio, servidores y entornos especializados.

Ediciones principales

Fedora Workstation

Edición de escritorio generalista, con GNOME como entorno predeterminado y herramientas para desarrolladores.

Fedora KDE Plasma Desktop

Experiencia de escritorio basada en KDE Plasma, con gran capacidad de personalización.

Fedora Server

Base flexible para servicios y tecnologías de centro de datos.

Fedora Spins y Labs

Variantes comunitarias y selecciones orientadas a escritorios o actividades concretas.

Tecnología y paquetes

Fedora utiliza RPM y DNF para gestionar paquetes. Suele incorporar versiones recientes de kernel, escritorios y herramientas, por lo que es interesante para quienes quieren probar tecnologías actuales sin construir manualmente una distribución desde cero. El ciclo de vida de cada versión es más corto que el de una LTS tradicional: conviene planificar las actualizaciones de versión.

Instalación y mantenimiento

  1. Descarga la edición adecuada desde Fedora Project.
  2. Verifica la imagen y prepara un USB de instalación.
  3. Prueba compatibilidad de gráficos, Wi-Fi y periféricos desde el entorno Live cuando esté disponible.
  4. Realiza copia de seguridad y revisa el particionado.
  5. Tras instalar, actualiza el sistema y consulta la documentación de la versión.
