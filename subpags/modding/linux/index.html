MODDING / GNU·LINUX

Linux

Una selección de distribuciones para escritorio, administración, desarrollo, seguridad y juego. Cada proyecto tiene su base, modelo de actualización y público objetivo.

Cómo elegir: valora el mantenimiento, el soporte de hardware, el modelo de actualizaciones, el gestor de paquetes y el propósito. En sistemas rolling release, planifica las actualizaciones y lee los avisos antes de aplicarlas.
