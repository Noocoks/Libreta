Linux Mint

Distribución GNU/Linux orientada al escritorio, conocida por una experiencia familiar, herramientas propias y una configuración lista para el uso cotidiano.

Ediciones

Linux Mint ofrece distintas ediciones que comparten la base de la distribución, pero utilizan entornos de escritorio diferentes:

Cinnamon

La edición más característica del proyecto: moderna, completa y con un escritorio desarrollado por el propio equipo de Mint.

MATE

Entorno tradicional, configurable y relativamente ligero, pensado para quienes prefieren una disposición clásica.

Xfce

Entorno ligero, con menor consumo de recursos y una interfaz sencilla.

Base y gestión

Las ediciones principales de Linux Mint se construyen sobre una base de Ubuntu LTS y utilizan paquetes DEB gestionados con APT, junto con las herramientas gráficas propias del proyecto. El proyecto también mantiene LMDE, una edición basada directamente en Debian; conviene distinguirla de las ediciones principales al consultar requisitos y repositorios.

Instalación y primeros pasos

  1. Descarga la imagen desde el sitio oficial y verifica su integridad siguiendo la guía del proyecto.
  2. Prueba el sistema desde el modo Live para comprobar Wi-Fi, gráficos, sonido y periféricos.
  3. Haz copia de seguridad y revisa el particionado antes de instalar.
  4. Tras la instalación, aplica las actualizaciones disponibles y comprueba los controladores recomendados.
  5. Configura Timeshift u otra estrategia de copias de seguridad antes de realizar cambios importantes.
