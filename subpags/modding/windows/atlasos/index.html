MODDING / WINDOWS / CONFIGURACIÓN

AtlasOS

Un proyecto de configuración de Windows orientado a reducir actividad en segundo plano y distracciones, ajustar privacidad y ofrecer más control sobre determinadas funciones del sistema.

Qué es y qué no es: Atlas no es una distribución independiente. Es un proyecto abierto que aplica una configuración (playbook) sobre una instalación compatible de Windows. El código y los cambios se publican para que puedan revisarse.

Versiones y compatibilidad: importante

Atlas ha cambiado de requisitos y método de instalación con el tiempo. La documentación vigente de Atlas Manager se centra en versiones públicas compatibles de Windows 11; Windows 10 y versiones antiguas de Atlas siguen procedimientos distintos y no deben tratarse como si fueran la misma instalación.

En particular, Atlas 0.4.1 pertenece a una generación anterior del proyecto. Si administras un equipo con esa versión, consulta su guía histórica y la ruta de actualización específica antes de aplicar instrucciones actuales. No intentes instalar la versión vigente encima de una instalación antigua siguiendo pasos genéricos.

La documentación actual indica restricciones por edición: Windows 11 Home, LTSC y Server no están admitidos para el flujo actual. También recomienda una instalación limpia, copia de seguridad, cuenta administradora compatible, UAC activo y requisitos de hardware de Windows 11. Comprueba siempre la tabla de compilaciones admitidas antes de empezar.

Objetivo y enfoque

AtlasOS —también denominado Atlas— busca mejorar la experiencia de Windows para usuarios entusiastas mediante ajustes de privacidad, usabilidad y rendimiento. Entre sus áreas de trabajo están la reducción de telemetría seleccionada, la eliminación de aplicaciones preinstaladas concretas, cambios en servicios y procesos en segundo plano y controles para revertir o modificar determinadas decisiones.

  • Privacidad: configura políticas y opciones para limitar parte de la recopilación de datos.
  • Actividad en segundo plano: ajusta servicios, aplicaciones y tareas seleccionadas.
  • Control: permite configurar individualmente distintos ajustes después de instalarlo.
  • Transparencia: el proyecto publica sus playbooks, scripts y documentación.

Instalación y mantenimiento

La documentación actual del proyecto sitúa Atlas Manager como método de instalación. El asistente comprueba el equipo, gestiona actualizaciones de Windows y Microsoft Store, permite elegir el flujo adecuado y aplica Atlas. También ofrece crear un medio de instalación con Atlas integrado.

  1. Lee la guía oficial y confirma que la versión, compilación y edición de Windows están dentro de los requisitos publicados para la versión de Atlas que vas a instalar.
  2. Realiza una copia de seguridad de los archivos del usuario y conserva instaladores, controladores y claves de recuperación necesarios.
  3. Para el flujo actual de Atlas Manager, prepara una instalación limpia de una edición compatible de Windows 11. No presupongas que una instalación de Windows 10 o una edición Home, LTSC o Server es compatible.
  4. Descarga Atlas Manager únicamente desde la web oficial o las publicaciones oficiales del repositorio. Es el método de instalación indicado por la documentación actual.
  5. Completa las decisiones del asistente y revisa la guía de configuración posterior.
  6. Instala controladores, actualizaciones y aplicaciones necesarias; comprueba el funcionamiento de Windows Update, Microsoft Store, audio, red, suspensión y periféricos.

Los requisitos y el procedimiento cambian entre versiones de Atlas. No reutilices instrucciones antiguas sin comprobarlas en la documentación vigente.

Checklist para preparar equipos de terceros

Antes de instalar Atlas en el ordenador de otra persona:

  • Confirma que el propietario entiende qué cambios se aplicarán y acepta el proceso.
  • Comprueba compatibilidad de juegos, anticheat, impresoras, VPN, software corporativo y periféricos.
  • Guarda copia de los datos personales y comprueba que puede restaurarse.
  • Apunta edición, versión y compilación de Windows, además del hardware y los controladores.
  • Explica qué funciones de Windows pueden cambiar y cómo consultar la documentación.
  • Después de instalar, prueba actualizaciones, Defender/Seguridad de Windows, red, sonido, Bluetooth, suspensión y aplicaciones críticas.
  • Entrega al usuario la información de cambios y las limitaciones que hayas detectado.

Importante: una modificación puede mejorar determinados aspectos, pero no garantiza más FPS, menor latencia ni mayor seguridad en todos los equipos. Mide antes y después y evita desactivar protecciones solo para conseguir un resultado de rendimiento.

Actualizaciones y reversión

Atlas debe mantenerse conforme a sus instrucciones oficiales. Antes de actualizar, revisa los cambios de la nueva versión y conserva copias de seguridad. No elimines manualmente componentes ni apliques scripts de terceros sin comprender sus efectos. Si necesitas retirar Atlas, consulta el procedimiento de la versión instalada: no presupongas que deshacer todos los cambios equivale a volver a un Windows original.
