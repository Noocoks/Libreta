Archivos, compresión y gestión documental

7-Zip

Archivador de archivos gratuito y open source con alta relación de compresión, formato 7z, soporte de numerosos formatos y herramientas gráficas y de consola.

Público objetivo: Usuarios que comprimen, descomprimen, verifican o cifran archivos.

Plataformas: Windows 11/10 y versiones anteriores; builds x86, x64 y ARM64. También existen ports comunitarios para otros sistemas.

Qué es y cómo funciona

7-Zip organiza archivos en contenedores y utiliza algoritmos como LZMA/LZMA2 para compresión. El formato 7z permite filtros, diccionarios y cifrado AES-256; ZIP también admite cifrado AES. La aplicación incluye interfaz gráfica, gestor de archivos y ejecutable de consola para automatización.

Funciones principales

Crear y extraer 7z, ZIP, TAR, GZIP, BZIP2 y XZ; extraer RAR, ISO, VHDX, WIM y muchos formatos más; cifrado AES-256, volúmenes divididos, pruebas de integridad y línea de comandos.

Instalación y configuración

Descarga desde 7-zip.org y elige la arquitectura correcta. Integra los formatos necesarios desde Options > Settings > System. Para archivos cifrados usa una contraseña robusta y activa la opción de cifrar nombres de archivo cuando el formato 7z lo permita.

Licencia y distribución

La mayor parte del código usa GNU LGPL; algunas partes usan BSD 3-clause y existe una restricción de licencia unRAR para determinados componentes. Se puede usar gratuitamente incluso en organizaciones comerciales.

Seguridad, privacidad y limitaciones

Un archivo comprimido puede contener ejecutables, enlaces o rutas maliciosas; inspecciona el contenido antes de extraerlo y evita extraer archivos desconocidos en carpetas privilegiadas. El cifrado AES-256 protege confidencialidad, pero no garantiza integridad ni seguridad del contenido. Mantén 7-Zip actualizado para corregir fallos de parsers.
