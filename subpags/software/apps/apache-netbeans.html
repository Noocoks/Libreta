Desarrollo y herramientas para programadores

Apache NetBeans

Entorno de desarrollo integrado (IDE) open source para Java y otros lenguajes, con editor, compilación, depuración, refactorización y gestión de proyectos.

Público objetivo: Estudiantes y desarrolladores que trabajan con Java, Maven, Gradle, PHP y otros proyectos compatibles.

Plataformas: Windows, macOS y GNU/Linux; requiere JDK 21 o posterior para las versiones actuales.

Qué es y cómo funciona

NetBeans organiza proyectos mediante módulos y sistemas de construcción como Ant, Maven y Gradle. El IDE integra editor con análisis semántico, compilación incremental, depurador, profiler, gestión de dependencias y extensiones. Su plataforma modular permite desarrollar plugins y aplicaciones basadas en NetBeans Platform.

Funciones principales

Editor Java, autocompletado, refactorización, depuración, profiling, Maven/Gradle/Ant, Git, integración con servidores y soporte para PHP/HTML/CSS/JavaScript mediante módulos.

Instalación y configuración

Instala primero un JDK 21+ compatible y descarga Apache NetBeans desde netbeans.apache.org o Apache Downloads. Configura el JDK del proyecto y el sistema de construcción. Crea un proyecto de prueba y comprueba compilación, ejecución y depuración antes de migrar proyectos existentes.

Compatibilidad y estado

Windows, macOS y GNU/Linux; requiere JDK 21 o posterior para las versiones actuales.

La documentación y el repositorio oficial indican JDK 21 o posterior para compilar y ejecutar NetBeans actual.

Licencia y distribución

Apache License 2.0; gratuito y de código abierto.

Seguridad, privacidad y limitaciones

Los plugins pueden ejecutar código dentro del IDE y acceder a archivos del proyecto. Instala módulos desde fuentes confiables. Mantén el JDK actualizado y no abras proyectos de procedencia desconocida si incluyen scripts de build que se ejecutan automáticamente.
