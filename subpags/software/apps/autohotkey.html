Productividad, organización y oficina

AutoHotkey

Lenguaje de scripting y herramienta de automatización para Windows que permite crear atajos, macros, hotstrings, ventanas y flujos de trabajo.

Público objetivo: Usuarios avanzados, técnicos y desarrolladores que automatizan tareas repetitivas en Windows.

Plataformas: Windows 7 o posterior según el proyecto; las releases actuales se prueban principalmente en Windows 11. x86 y x64.

Qué es y cómo funciona

AutoHotkey interpreta scripts `.ahk` que registran hotkeys, hotstrings, callbacks y acciones sobre ventanas, teclado, ratón, portapapeles y APIs de Windows. Los scripts pueden ejecutarse mediante el intérprete o compilarse con Ahk2Exe. La versión 2 introdujo cambios incompatibles en sintaxis respecto a v1.

Funciones principales

Atajos globales, expansión de texto, macros, automatización de ventanas, automatización de teclado/ratón, GUI, acceso a COM/DLL y compilación de scripts.

Instalación y configuración

Descarga AutoHotkey v2 desde autohotkey.com. Crea un archivo `.ahk` y ejecútalo con el intérprete. Aprende primero variables, funciones, hotkeys y control de flujo desde la documentación oficial. Si necesitas mantener scripts antiguos, identifica si fueron escritos para v1 o v2 y no los ejecutes sin revisarlos.

Compatibilidad y estado

Windows 7 o posterior según el proyecto; las releases actuales se prueban principalmente en Windows 11. x86 y x64.

AutoHotkey v2.0.32 publicado el 20 de noviembre de 2026 según el repositorio oficial. El proyecto indica que v2 debería funcionar en Windows 7+, pero las releases se prueban en Windows 11.

Licencia y distribución

GPL-2.0; software libre y gratuito.

Seguridad, privacidad y limitaciones

Un script puede enviar teclas, hacer clic, leer/escribir archivos y ejecutar programas con los permisos del usuario. No ejecutes scripts descargados sin inspeccionar el código. Los scripts elevados pueden modificar el sistema; solicita UAC solo cuando sea imprescindible. AutoHotkey v1 ya no se mantiene activamente y v2 no es retrocompatible en sintaxis.
