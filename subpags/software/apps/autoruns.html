Administración y mantenimiento del sistema

Autoruns

Utilidad Sysinternals que enumera ubicaciones de inicio automático de Windows para identificar programas, servicios, controladores y extensiones que se cargan al arrancar o iniciar sesión.

Público objetivo: Administradores, técnicos y usuarios avanzados que investigan el arranque y persistencia de programas.

Plataformas: Windows; la documentación actual de Sysinternals cubre versiones cliente y servidor compatibles.

Qué es y cómo funciona

Autoruns consulta numerosas ubicaciones de autoarranque, incluidas carpetas Startup, claves Run/RunOnce, servicios, drivers, extensiones de Explorer, Winlogon y otras extensiones del sistema. Autorunsc ofrece una interfaz de línea de comandos para automatizar inventarios y análisis. La herramienta enumera entradas; no determina por sí sola que sean maliciosas.

Funciones principales

Vista por categorías, búsqueda, ocultación de entradas firmadas de Microsoft, verificación de firmas, comprobación con VirusTotal según configuración, exportación y automatización con Autorunsc.

Instalación y configuración

Descarga la suite desde Microsoft Sysinternals o la Microsoft Store. Ejecuta Autoruns como administrador para inspeccionar el sistema completo. Activa Hide Microsoft Entries y Verify Code Signatures para facilitar el análisis; guarda una copia del inventario antes de deshabilitar entradas.

Compatibilidad y estado

Windows; la documentación actual de Sysinternals cubre versiones cliente y servidor compatibles.

Licencia y distribución

Freeware de Microsoft Sysinternals; gratuita, pero no es software open source.

Seguridad, privacidad y limitaciones

Deshabilitar una entrada puede impedir que funcionen drivers, servicios, software de seguridad o componentes del sistema. No elimines entradas desconocidas por su nombre o ubicación únicamente; comprueba firma, editor, ruta y función. Las consultas VirusTotal pueden compartir hashes con un servicio externo; revisa la política y configuración antes de activarlas.
