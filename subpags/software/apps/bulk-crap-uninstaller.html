Administración y mantenimiento del sistema

Bulk Crap Uninstaller (BCUninstaller)

Desinstalador masivo y open source para Windows que detecta aplicaciones, restos y desinstaladores de múltiples tecnologías con mínima intervención manual.

Público objetivo: Administradores y usuarios avanzados que mantienen muchos equipos o instalaciones de software.

Plataformas: Windows; compatible con aplicaciones Win32, Microsoft Store y diversos instaladores.

Qué es y cómo funciona

BCUninstaller enumera aplicaciones instaladas mediante distintas fuentes del sistema y detecta desinstaladores conocidos. Puede ejecutar lotes de desinstalación, detectar aplicaciones huérfanas y buscar restos. Utiliza listas predefinidas y automatización, pero mantiene confirmaciones y vistas previas para reducir acciones accidentales.

Funciones principales

Desinstalación masiva, detección de aplicaciones huérfanas, limpieza de restos, soporte para Windows Store, Steam, MSI, Inno Setup, NSIS y otros instaladores, automatización y exportación de listas.

Instalación y configuración

Descarga desde bcuninstaller.com o GitHub Releases. Revisa el inventario detectado y marca únicamente las aplicaciones que realmente quieres retirar. Ejecuta primero un lote pequeño y comprueba los resultados antes de automatizar tareas mayores.

Compatibilidad y estado

Windows; compatible con aplicaciones Win32, Microsoft Store y diversos instaladores.

Seguridad, privacidad y limitaciones

La desinstalación masiva puede eliminar componentes compartidos o perfiles de usuario. No ejecutes operaciones silenciosas sobre aplicaciones del sistema sin revisar dependencias. Los archivos de configuración y scripts de automatización deben mantenerse bajo control de versiones.
