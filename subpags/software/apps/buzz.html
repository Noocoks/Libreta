Audio, música y producción sonora

Buzz

Aplicación de escritorio para transcribir y traducir audio y vídeo localmente mediante modelos Whisper, con soporte de aceleración por hardware.

Público objetivo: Estudiantes, periodistas, investigadores y creadores que transcriben grabaciones.

Plataformas: Windows, macOS y GNU/Linux; soporte de aceleración según GPU y backend.

Qué es y cómo funciona

Buzz integra modelos de reconocimiento automático del habla de Whisper y backends como Faster-Whisper y whisper.cpp. Los modelos se descargan y almacenan localmente y el audio se procesa en el equipo. Puede utilizar API remotas opcionales, pero el flujo offline no necesita enviar audio a un servicio cloud.

Funciones principales

Transcripción de archivos de audio/vídeo, traducción al inglés, grabación en directo, identificación de hablantes, separación de voz, CUDA, Apple Silicon, Vulkan, watch folders, CLI y exportación TXT/SRT/VTT.

Instalación y configuración

Descarga desde el repositorio oficial o su web de documentación. Selecciona un modelo según memoria y velocidad: modelos grandes mejoran precisión pero consumen más recursos. En GPU NVIDIA instala el backend CUDA compatible; para equipos modestos prueba whisper.cpp o un modelo pequeño. Comprueba el idioma manualmente cuando lo conozcas.

Compatibilidad y estado

Windows, macOS y GNU/Linux; soporte de aceleración según GPU y backend.

Seguridad, privacidad y limitaciones

El modo local mantiene el audio en el equipo, pero la función OpenAI API transmite el contenido al servicio remoto si la configuras. Los modelos descargados ocupan espacio y deben proceder de fuentes confiables. La identificación de hablantes es una estimación y no debe utilizarse como prueba de identidad.
