Videojuegos y experiencia gaming

CapFrameX

Herramienta de captura y análisis de rendimiento en juegos para Windows que registra FPS, frametimes, percentiles, sensores y resultados comparables.

Público objetivo: Jugadores, reviewers y entusiastas que comparan rendimiento de CPU, GPU y configuraciones gráficas.

Plataformas: Windows 10 y Windows 11; x64. La versión actual requiere .NET 10 Desktop Runtime.

Qué es y cómo funciona

CapFrameX se apoya en PresentMon para capturar eventos de presentación de fotogramas y construir métricas de tiempo entre frames. Añade gestión de capturas, análisis estadístico, comparaciones, gráficos y telemetría de sensores. El frametime permite detectar irregularidades que una media de FPS oculta.

Funciones principales

Captura de FPS y frametimes, percentiles, frame variance, overlays, logging de sensores, comparativas de sesiones y análisis de tecnologías de generación de frames.

Instalación y configuración

Descarga desde el repositorio oficial. La versión estable indicada en las releases es 1.9.1; la rama 1.9.2.1 aparece como beta. Instala .NET 10 Desktop Runtime x64 y los componentes que indique el instalador. Configura la tecla de captura, el proceso de juego y los sensores; realiza varias pasadas con la misma escena para comparar resultados.

Compatibilidad y estado

Windows 10 y Windows 11; x64. La versión actual requiere .NET 10 Desktop Runtime.

CapFrameX 1.9.1 es la versión estable; 1.9.2.1 se identifica como beta en las releases consultadas. Requiere .NET 10 Desktop Runtime x64.

Licencia y distribución

Software gratuito; consulta el repositorio y las licencias de sus componentes. Se basa en Intel PresentMon y componentes de monitorización.

Seguridad, privacidad y limitaciones

El overlay y los componentes de captura utilizan hooks o capas específicas para observar la presentación de frames; algunos anti-cheat pueden impedir su uso o considerarlo incompatible. Cierra el juego antes de actualizar y verifica los ZIP mediante SHA-256. No compares métricas obtenidas con configuraciones, drivers o versiones distintas sin anotarlo.
