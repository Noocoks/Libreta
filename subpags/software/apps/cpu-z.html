Hardware, diagnóstico y periféricos

CPU-Z

Utilidad de CPUID que identifica y muestra información técnica del procesador, placa base, chipset, memoria y frecuencias en tiempo real.

Público objetivo: Técnicos y usuarios que necesitan identificar componentes y comprobar configuración de hardware.

Plataformas: Windows x86/x64 y ARM64; también existe una versión para Android.

Qué es y cómo funciona

CPU-Z consulta interfaces del sistema y registros de hardware para identificar CPU, stepping, package, instrucciones, placa base, chipset y módulos de memoria. Puede leer datos SPD cuando la plataforma y el controlador lo permiten y muestra frecuencias de CPU y memoria en tiempo real. La información depende del soporte de la plataforma y de permisos del sistema.

Funciones principales

Identificación de CPU, placa base, chipset, BIOS, memoria, SPD, timings y frecuencias; validación y generación de informes.

Instalación y configuración

Descarga el instalador o ZIP portable desde CPUID. Ejecuta la aplicación y revisa las pestañas CPU, Mainboard, Memory y SPD. Para compartir un diagnóstico, utiliza la función de validación y evita publicar números de serie o identificadores que puedan revelar información del equipo.

Compatibilidad y estado

Windows x86/x64 y ARM64; también existe una versión para Android.

CPU-Z 3.02 aparece en la página oficial consultada. La web declara soporte completo para Windows 11 y distribuciones x86/x64 y ARM64.

Licencia y distribución

Freeware para Windows; no es software open source. CPUID ofrece un SDK profesional separado.

Seguridad, privacidad y limitaciones

CPU-Z es una herramienta de lectura de información, pero puede instalar componentes de bajo nivel para determinadas consultas. Descarga solo desde CPUID y revisa los avisos del instalador. No confundas las frecuencias reportadas con una prueba de estabilidad ni uses datos SPD como única fuente para configurar overclock.
