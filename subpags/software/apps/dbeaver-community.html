Desarrollo y herramientas para programadores

DBeaver Community

Cliente gráfico universal de bases de datos para conectarse a motores SQL y gestionar esquemas, consultas, datos y metadatos.

Público objetivo: Desarrolladores, administradores de bases de datos, estudiantes de SQL y equipos de datos.

Plataformas: Windows 10 o posterior, macOS 11 o posterior y distribuciones Linux modernas; hay paquetes x86 y ARM según plataforma.

Qué es y cómo funciona

Cliente gráfico universal de bases de datos para conectarse a motores SQL y gestionar esquemas, consultas, datos y metadatos.

DBeaver utiliza conectores JDBC para comunicarse con motores de bases de datos. La interfaz abstrae conexiones, metadatos, editores SQL y herramientas de transferencia, pero las capacidades disponibles dependen del driver y del servidor.

Funciones principales

Exploración de esquemas, editor SQL, autocompletado, navegación de metadatos, importación/exportación, diagramas ER y gestión de conexiones. Algunas capacidades avanzadas pertenecen a PRO.

Instalación y primera configuración

Instala Community desde el sitio oficial. Crea una conexión seleccionando el motor y proporciona host, puerto, base de datos y credenciales. Comprueba TLS, permisos y driver; guarda credenciales solo si el equipo está protegido.

Seguridad, privacidad y limitaciones

La edición Community no incluye todas las funciones de PRO. Las operaciones de modificación masiva o eliminación pueden afectar datos reales: trabaja con transacciones, permisos mínimos y copias de seguridad. Las distribuciones oficiales incluyen OpenJDK en sus paquetes actuales; revisa las notas de versión antes de instalar Java por separado.
