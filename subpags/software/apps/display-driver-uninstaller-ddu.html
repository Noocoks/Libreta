Administración y mantenimiento del sistema

Display Driver Uninstaller (DDU)

Herramienta especializada para eliminar restos de controladores gráficos NVIDIA, AMD e Intel y preparar una instalación limpia cuando existe un problema de drivers.

Público objetivo: Técnicos y usuarios avanzados que solucionan conflictos o fallos persistentes de controladores gráficos.

Plataformas: Windows 7, 8, 8.1, 10 y 11; x86/x64, .NET Framework 4.8 o posterior.

Qué es y cómo funciona

DDU elimina paquetes, servicios, carpetas, claves y entradas de controladores gráficos para dejar el sistema preparado para una instalación limpia. Puede operar en Modo seguro para reducir archivos bloqueados y procesos que interfieran con la eliminación.

Funciones principales

Limpieza de controladores NVIDIA, AMD e Intel, limpieza básica de ciertos drivers de audio Realtek, bloqueo opcional de descarga automática de drivers desde Windows Update y modos de limpieza/reinicio/apagado.

Instalación y configuración

Descarga desde Wagnardsoft, extrae en una carpeta local y lee el README. Descarga primero el controlador que vayas a instalar, crea un punto de restauración y entra en Modo seguro. Selecciona GPU y fabricante y utiliza Clean and restart para una reinstalación normal; Clean and shutdown se reserva para cambiar físicamente de GPU.

Compatibilidad y estado

Windows 7, 8, 8.1, 10 y 11; x86/x64, .NET Framework 4.8 o posterior.

DDU 18.1.6.0 publicado en 2026 según Wagnardsoft; requiere .NET Framework 4.8 y Windows 7–11. El desarrollador recomienda Modo seguro para mayor estabilidad.

Licencia y distribución

Freeware de Wagnardsoft con donaciones opcionales; no es open source ni está afiliado a NVIDIA, AMD o Intel.

Seguridad, privacidad y limitaciones

Es una operación de bajo nivel y puede dejar el sistema sin controlador gráfico temporalmente. No lo ejecutes por rutina en cada actualización: úsalo cuando una guía de diagnóstico recomiende una limpieza completa. Conserva el instalador del nuevo driver y un método de recuperación; no borres carpetas de otros fabricantes sin comprender la selección.
