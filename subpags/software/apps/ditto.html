Archivos, compresión y gestión documental

Ditto

Gestor de historial del portapapeles de Windows que conserva texto, imágenes, HTML y otros formatos para reutilizarlos posteriormente.

Público objetivo: Usuarios que copian y pegan con frecuencia y necesitan recuperar elementos anteriores del portapapeles.

Plataformas: Windows; instalador, versión portable y Microsoft Store.

Qué es y cómo funciona

Ditto escucha los cambios del portapapeles de Windows y almacena elementos en una base de datos local. Permite buscar, agrupar, sincronizar entre equipos mediante red local y volver a insertar elementos en la aplicación activa. El proyecto declara funcionamiento local, sin cuenta, nube ni telemetría.

Funciones principales

Historial de texto, imágenes, HTML y formatos personalizados; búsqueda, grupos, atajos, pegado rápido, sincronización entre equipos y versión portable.

Instalación y configuración

Descarga desde el sitio oficial o GitHub Releases. Configura el atajo de acceso y el límite de historial. Revisa exclusiones y reglas para aplicaciones que manejan contraseñas; elimina entradas sensibles del historial cuando ya no sean necesarias.

Compatibilidad y estado

Windows; instalador, versión portable y Microsoft Store.

Ditto 3.25.113.0 aparece como release en el README oficial consultado. El proyecto declara que no requiere login, no usa nube y no incorpora telemetría.

Licencia y distribución

GPL-3.0; gratuito y de código abierto.

Seguridad, privacidad y limitaciones

El portapapeles puede contener contraseñas, tokens, datos personales y documentos. El historial conserva esos datos localmente; protege el perfil de Windows, restringe el acceso a la base de datos y limpia entradas sensibles. La sincronización entre equipos amplía la superficie de exposición y debe usarse solo en redes de confianza.
