Desarrollo y herramientas para programadores

Docker Desktop

Entorno de desarrollo para construir, ejecutar y administrar contenedores y servicios mediante Docker Engine, Docker CLI y Docker Compose.

Público objetivo: Desarrolladores, estudiantes y equipos que reproducen servicios en entornos aislados.

Plataformas: Windows 10/11 compatibles, macOS y Linux; los backends y requisitos cambian por sistema.

Qué es y arquitectura

Docker Desktop integra la interfaz de gestión, CLI, Docker Engine, BuildKit y Docker Compose. En Windows, el backend WSL 2 ejecuta un kernel Linux real dentro de una distribución gestionada por Docker Desktop; el motor usa namespaces, cgroups, sistemas de archivos por capas y redes virtuales para aislar contenedores. Una imagen se compone de capas reutilizables; un contenedor añade una capa de escritura temporal. Volúmenes y bind mounts permiten persistir o compartir datos.

Funciones principales

Construcción de imágenes, ejecución de contenedores, redes, volúmenes, Compose, gestión de imágenes, extensiones y administración de contextos. La disponibilidad de algunas funciones depende de la edición y la suscripción.

Instalación y configuración

En Windows comprueba que la virtualización de hardware está habilitada y que WSL está actualizado. La documentación consultada exige WSL 2.1.5 como mínimo para el backend WSL 2. Instala Docker Desktop desde la web oficial, selecciona el backend adecuado y habilita la integración únicamente en las distribuciones WSL que utilices. Comprueba con `wsl --version`, `wsl -l -v`, `docker version` y `docker compose version`.

Compatibilidad y estado

Windows 10/11 compatibles, macOS y Linux; los backends y requisitos cambian por sistema.

Docker Desktop mantiene soporte para backends WSL 2 y Hyper-V en Windows; Docker VMM se documenta como beta en la información consultada.

Licencia y modelo de distribución

Docker Subscription Service Agreement. Gratuito para uso personal, educación, proyectos open source no comerciales y pequeñas empresas que cumplan simultáneamente los límites publicados. Organizaciones grandes y entidades gubernamentales pueden necesitar suscripción de pago.

Seguridad, privacidad y limitaciones

No confundas la licencia de Docker Desktop con la de Docker Engine/Moby y sus componentes open source. En Windows Home/Education se limita el soporte a contenedores Linux; los contenedores Windows requieren ediciones Pro o Enterprise. No montes el socket del motor ni uses privileged sin una necesidad justificada. Mantén imágenes base actualizadas, usa usuarios no privilegiados y evita incluir secretos en capas.
