Audio, música y producción sonora

EarTrumpet

Mezclador de volumen para Windows que permite controlar el nivel de cada aplicación, cambiar dispositivos de salida y gestionar sesiones de audio.

Público objetivo: Usuarios que necesitan controlar por separado el volumen y salida de aplicaciones en Windows.

Plataformas: Windows 10 versión 1803 o posterior y Windows 11.

Qué es y cómo funciona

EarTrumpet utiliza las APIs de sesiones de audio de Windows para enumerar aplicaciones que reproducen sonido y ajustar su volumen por sesión. Puede mover aplicaciones entre dispositivos de salida y administrar el dispositivo predeterminado desde el área de notificación.

Funciones principales

Volumen independiente por aplicación, medidores multicanal, cambio de dispositivo de reproducción, dispositivo predeterminado, mixer independiente, atajos y temas claros/oscuros.

Instalación y configuración

Instala desde Microsoft Store o utiliza `winget install File-New-Project.EarTrumpet`. Abre el icono del área de notificación, ajusta el volumen por aplicación y mueve las sesiones a la salida deseada. Puedes desactivar el icono de volumen original si prefieres utilizar solo EarTrumpet.

Compatibilidad y estado

Windows 10 versión 1803 o posterior y Windows 11.

Verificación editorial 28-11-2026. El repositorio oficial declara compatibilidad con Windows 10 1803+ y Windows 11.
