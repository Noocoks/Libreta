Archivos, compresión y gestión documental

Everything

Buscador de nombres de archivos y carpetas para Windows que construye un índice rápido y actualiza resultados en tiempo real.

Público objetivo: Usuarios que buscan archivos en discos con grandes cantidades de carpetas y documentos.

Plataformas: Windows XP y posteriores, incluido Windows 10/11; instalador y versión portable x86/x64/ARM.

Qué es y cómo funciona

Everything utiliza la Master File Table de NTFS para indexar nombres y rutas rápidamente. El USN Change Journal permite detectar cambios y mantener el índice actualizado sin recorrer todo el disco. En sistemas de archivos no NTFS puede configurarse indexado por carpetas mediante exploración convencional.

Funciones principales

Búsqueda instantánea por nombre/ruta, filtros, expresiones, marcadores, indexación NTFS, actualizaciones en tiempo real, versión portable y servidores HTTP/FTP/ETP opcionales.

Instalación y configuración

Descarga desde voidtools.com. Instala el servicio Everything para indexar volúmenes NTFS mientras el usuario trabaja sin privilegios de administrador, o configura el modo portable. Añade solo los volúmenes y carpetas que quieras indexar y revisa las opciones de indexación.

Compatibilidad y estado

Windows XP y posteriores, incluido Windows 10/11; instalador y versión portable x86/x64/ARM.

Verificación editorial 28-11-2026. Everything es freeware y compatible con Windows 10/11; los volúmenes NTFS utilizan MFT y USN Journal.

Licencia y distribución

Freeware propietario gratuito; el desarrollador solicita donaciones opcionales.

Seguridad, privacidad y limitaciones

El servicio de indexación necesita permisos para consultar metadatos del sistema de archivos. Las funciones de servidor HTTP/FTP/ETP pueden exponer nombres y rutas; mantenlas desactivadas salvo necesidad y no las publiques en redes no confiables. La búsqueda por nombre no equivale a indexar el contenido de los archivos.
