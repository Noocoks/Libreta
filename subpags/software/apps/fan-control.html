Hardware, diagnóstico y periféricos

Fan Control

Aplicación de Windows para monitorizar sensores y configurar curvas de ventiladores de CPU, GPU y caja según las capacidades del hardware.

Público objetivo: Usuarios que ajustan refrigeración, ruido y temperaturas de equipos de sobremesa.

Plataformas: Windows 10 y Windows 11; la detección depende de placa base, controladores, GPU y sensores disponibles.

Qué es y cómo funciona

Fan Control obtiene lecturas de sensores y canales de ventilador mediante bibliotecas y controladores compatibles. Permite asociar una fuente de temperatura a una salida PWM/DC y definir curvas, mezclas o reglas. No todos los encabezados, controladores embebidos o GPUs exponen sus canales a Windows.

Funciones principales

Detección de sensores, lectura de temperaturas y RPM, curvas personalizadas, mezcla de varias temperaturas, perfiles, control de GPU compatible y calibración de ventiladores.

Instalación y configuración

Descarga desde el repositorio oficial de Rem0o. Ejecuta el asistente de configuración y comprueba qué sensores y salidas detecta. Identifica cada ventilador con una prueba controlada, establece límites mínimos seguros y crea curvas graduales. Guarda un perfil de respaldo antes de cambiar configuraciones.

Compatibilidad y estado

Windows 10 y Windows 11; la detección depende de placa base, controladores, GPU y sensores disponibles.

Verificación editorial 28-11-2026. La disponibilidad de control depende del hardware; el proyecto no garantiza soporte universal para todas las placas o ventiladores.

Licencia y distribución

Freeware gratuito con opción de apoyar al desarrollador; no debe confundirse con proyectos de control de ventiladores de otros sistemas.

Seguridad, privacidad y limitaciones

Un valor PWM incorrecto puede detener un ventilador o provocar sobrecalentamiento. No desactives protecciones del firmware ni fuerces canales cuya función no esté identificada. Algunas funciones requieren drivers de sensores; instálalos solo desde el paquete oficial y comprueba que el control BIOS/UEFI no entre en conflicto.
