Archivos, compresión y gestión documental

Files

Administrador de archivos moderno para Windows con pestañas, paneles, etiquetas, vistas personalizadas e integración con servicios y ubicaciones de almacenamiento.

Público objetivo: Usuarios de Windows que quieren una alternativa al Explorador de archivos con funciones adicionales.

Plataformas: Windows 10 y Windows 11; los requisitos concretos dependen de la versión estable o preview.

Qué es y cómo funciona

Files está construido sobre tecnologías modernas de Windows y una interfaz XAML/WinUI. Integra navegación por pestañas, paneles, etiquetas, vista de columnas, operaciones de archivos, servicios de almacenamiento y extensiones. El proyecto mantiene el desarrollo abierto en GitHub y ofrece versiones estable y preview.

Funciones principales

Pestañas, panel dual, etiquetas, vista de columnas, vista previa, integración con servicios en nube, acciones contextuales, terminal y temas.

Instalación y configuración

Descarga desde Microsoft Store o GitHub Releases. Prueba primero la versión estable junto al Explorador de Windows; la versión Preview puede instalarse en paralelo y contiene funciones experimentales. Configura ubicaciones favoritas y revisa permisos de los servicios cloud que conectes.

Compatibilidad y estado

Windows 10 y Windows 11; los requisitos concretos dependen de la versión estable o preview.

Verificación editorial 28-11-2026. El proyecto ofrece instalador clásico y distribución Microsoft Store; las licencias de los componentes se detallan en el repositorio.

Licencia y distribución

Proyecto open source con componentes bajo MIT y MPL; el instalador clásico puede descargarse desde GitHub y existe distribución mediante Microsoft Store.

Seguridad, privacidad y limitaciones

Los servicios cloud y extensiones pueden acceder a archivos y metadatos de las ubicaciones conectadas. Comprueba permisos antes de autenticar cuentas. No utilices builds preview para gestionar datos críticos sin copias de seguridad y revisa los cambios de versión antes de convertirlo en gestor predeterminado.
