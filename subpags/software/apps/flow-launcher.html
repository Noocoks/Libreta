Productividad, organización y oficina

Flow Launcher

Lanzador de aplicaciones y buscador rápido para Windows que centraliza búsqueda de programas, archivos, comandos, marcadores y plugins.

Público objetivo: Usuarios avanzados y desarrolladores que quieren ejecutar acciones sin navegar por menús.

Plataformas: Windows 10 y Windows 11; instalador y paquete portable.

Qué es y cómo funciona

Flow Launcher permanece residente y muestra una barra de búsqueda mediante un atajo global. Los plugins consultan fuentes como programas, archivos, calculadora, ajustes del sistema, shell, URL y servicios web. La arquitectura permite ampliar funciones mediante plugins comunitarios.

Funciones principales

Búsqueda de programas y archivos, calculadora, historial, marcadores, comandos de sistema, shell, búsquedas web, plugins y temas.

Instalación y configuración

Descarga desde flowlauncher.com o GitHub Releases. Configura el atajo global y los directorios indexados. Instala plugins desde Plugin Store solo cuando necesites una función y comprueba el autor y el repositorio de cada extensión.

Compatibilidad y estado

Windows 10 y Windows 11; instalador y paquete portable.

Flow Launcher 2.1.4 publicado el 20 de septiembre de 2026. La documentación indica Windows 10+ como requisito mínimo.

Licencia y distribución

MIT; gratuito y de código abierto.

Seguridad, privacidad y limitaciones

Los plugins pueden ejecutar comandos, consultar archivos o acceder a servicios externos. Instala únicamente plugins de confianza y revisa sus permisos y código. El instalador puede mostrar SmartScreen porque las releases no siempre están firmadas; verifica que el archivo procede del dominio o repositorio oficial antes de permitirlo.
