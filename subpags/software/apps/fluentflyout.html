Personalización y escritorio

FluentFlyout

Aplicación open source que sustituye los paneles emergentes de volumen y controles multimedia de Windows por flyouts personalizables.

Público objetivo: Usuarios de Windows que quieren modernizar controles de volumen, reproducción y teclas especiales.

Plataformas: Windows 10 build 19041 o posterior y Windows 11; x64 y ARM64.

Qué es y cómo funciona

FluentFlyout se integra con los controles multimedia y de volumen de Windows y presenta paneles independientes para volumen, mezclador por aplicación, medios, teclas de bloqueo y widgets de taskbar. Utiliza las APIs de Windows System Media Transport Controls (SMTC) para mostrar metadatos y controles de reproducción compatibles.

Funciones principales

Flyout de volumen, mezclador por aplicación, selección de salida, controles multimedia, Caps/Num Lock, widget multimedia y visualizador en taskbar, temas Mica/Acrylic y personalización.

Instalación y configuración

Instala desde Microsoft Store o GitHub Releases. La versión GitHub requiere actualizaciones manuales; la Store ofrece actualización automática y extras opcionales de pago. Configura los flyouts desde Settings y activa solo los que utilices.

Compatibilidad y estado

Windows 10 build 19041 o posterior y Windows 11; x64 y ARM64.

Verificación editorial 28-11-2026. Requisitos oficiales: Windows 10 build 19041+, 4 GB RAM y x64/ARM64; Windows 11 recomendado.

Licencia y distribución

MIT; gratuito y de código abierto. La versión GitHub es gratuita con todas las funciones; la edición Microsoft Store tiene extras opcionales de pago.

Seguridad, privacidad y limitaciones

La aplicación necesita integrarse con el shell y los controles multimedia. Descarga desde el repositorio o Store oficiales y evita builds de terceros. Las funciones de media dependen de que el reproductor implemente SMTC; algunos reproductores pueden requerir plugins o no exponer todos los controles.
