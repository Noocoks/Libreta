Administración y mantenimiento del sistema

Geek Uninstaller

Desinstalador portable para Windows que elimina aplicaciones y busca archivos o claves residuales después de ejecutar el desinstalador estándar.

Público objetivo: Usuarios domésticos que quieren una herramienta ligera para desinstalar programas.

Plataformas: Windows 7, 8, 8.1, 10 y 11; x86 y x64. Requiere permisos de administrador.

Qué es y cómo funciona

Geek Uninstaller consulta la lista de programas instalados, ejecuta el desinstalador correspondiente y permite una búsqueda posterior de residuos. Force Removal sirve para entradas de programas que ya no tienen un desinstalador funcional, por lo que modifica archivos y Registro de forma más directa.

Funciones principales

Desinstalación estándar, búsqueda de restos, Force Removal, vista de aplicaciones Windows y modalidad portable ZIP/7z.

Instalación y configuración

Descarga el ZIP o 7z gratuito desde geekuninstaller.com, extrae el ejecutable y ejecútalo como administrador cuando sea necesario. Selecciona una aplicación, usa Uninstall y revisa la lista de restos antes de eliminarlos. Reserva Force Removal para instalaciones dañadas y con una copia de seguridad previa.

Compatibilidad y estado

Windows 7, 8, 8.1, 10 y 11; x86 y x64. Requiere permisos de administrador.

Seguridad, privacidad y limitaciones

La edición Free solo está licenciada para uso personal. La eliminación forzada puede borrar archivos o claves compartidas; no la utilices como limpieza automática. Comprueba el nombre, editor y ruta del programa antes de actuar.
