Videojuegos y experiencia gaming

Heroic Games Launcher

Lanzador de juegos multiplataforma y open source que unifica bibliotecas de Epic Games Store, GOG y Amazon Games, además de juegos añadidos manualmente.

Público objetivo: Jugadores que quieren gestionar varias tiendas desde una interfaz común, especialmente en Linux y Steam Deck.

Plataformas: Windows 10/11, macOS 12+ y GNU/Linux; compatibilidad y runtimes dependen del juego.

Qué es y cómo funciona

Heroic proporciona una interfaz gráfica para herramientas de línea de comandos: Legendary para Epic Games, gogdl para GOG y Nile para Amazon Games. Gestiona autenticación, descarga, instalación, actualización, reparación y lanzamiento. En Linux puede integrar Wine, Proton y otras capas de compatibilidad; no sustituye a los servicios DRM ni a los anti-cheat de cada juego.

Funciones principales

Bibliotecas de Epic/GOG/Amazon, instalación y actualización, importación de juegos existentes, sincronización de partidas guardadas, Wine/Proton en Linux, temas, cola de descargas y modo de pantalla completa.

Instalación y configuración

Descarga desde heroicgameslauncher.com o GitHub Releases. Inicia sesión mediante los flujos oficiales de cada tienda y revisa los permisos de cuenta. En Linux selecciona un runner compatible por juego; en Windows y macOS comprueba los requisitos propios del título. Usa la opción de importar antes de volver a descargar juegos ya instalados.

Compatibilidad y estado

Windows 10/11, macOS 12+ y GNU/Linux; compatibilidad y runtimes dependen del juego.

Verificación editorial 28-11-2026. La wiki del proyecto indica soporte para Windows 10/11, macOS 12+ y distribuciones Linux como Ubuntu, Fedora y Arch.

Licencia y distribución

GPL-3.0; gratuito, open source, sin anuncios ni plan de pago según el proyecto.

Seguridad, privacidad y limitaciones

Heroic almacena tokens de autenticación de las tiendas; protege el perfil del usuario y no compartas sus archivos de configuración. La compatibilidad online y anti-cheat depende de cada juego y sistema operativo. Las funciones experimentales pueden cambiar o dejar de funcionar.
