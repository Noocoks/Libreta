Desarrollo y herramientas para programadores

Java Development Kit (JDK)

Kit de desarrollo de Java que incluye compilador, herramientas de diagnóstico, runtime y bibliotecas para construir y ejecutar aplicaciones Java.

Público objetivo: Estudiantes, desarrolladores y administradores que compilan, prueban o ejecutan aplicaciones Java.

Plataformas: Windows, macOS y GNU/Linux; distribuciones x64 y ARM64 según proveedor.

Qué es y cómo funciona

El JDK incluye javac, el runtime Java, herramientas como javadoc, jar, jlink, jcmd y utilidades de depuración. El compilador transforma .java en bytecode .class; la Java Virtual Machine (JVM) carga, verifica, interpreta y compila código mediante JIT durante la ejecución. Las versiones LTS y no LTS tienen ciclos de soporte diferentes.

Funciones principales

Compilación, ejecución, empaquetado JAR, documentación, depuración, profiling, gestión de módulos, creación de runtimes personalizados y herramientas de diagnóstico.

Instalación y configuración

Elige primero el proveedor y versión exigidos por tu proyecto. Para uso general puedes utilizar Oracle JDK 25 bajo NFTC o una build OpenJDK como Eclipse Temurin. Descarga el paquete correcto, configura JAVA_HOME y PATH y verifica con java -version y javac -version. Mantén las versiones de JDK por proyecto mediante herramientas de gestión si trabajas con varias.

Compatibilidad y estado

Windows, macOS y GNU/Linux; distribuciones x64 y ARM64 según proveedor.

Oracle JDK 25.0.5.1 aparece como descarga actual en la página oficial; la licencia NFTC permite uso en producción hasta septiembre de 2028. Oracle JDK 21.0.13+ y versiones anteriores tienen condiciones diferentes.

Licencia y distribución

Depende de la distribución. Oracle JDK 25.0.5.1 se publica bajo Oracle No-Fee Terms and Conditions (NFTC), gratuito para todos los usuarios hasta septiembre de 2028; Oracle OpenJDK se distribuye bajo GPLv2 con Classpath Exception. Otros proveedores tienen sus propios calendarios y licencias.

Seguridad, privacidad y limitaciones

No confundas JDK con JRE ni Oracle JDK con OpenJDK. Las licencias y el soporte cambian según proveedor y release; revisa el acuerdo antes de desplegar en producción. Mantén actualizaciones de seguridad y evita versiones antiguas sin soporte. Las aplicaciones Java pueden cargar bibliotecas nativas y dependencias de terceros.
