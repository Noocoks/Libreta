Descargas y medios de instalación

JDownloader 2

Gestor de descargas multiplataforma que automatiza descargas desde alojamientos web, procesa enlaces, archivos divididos y captchas compatibles.

Público objetivo: Usuarios que descargan archivos grandes o múltiples desde servicios de alojamiento y enlaces directos.

Plataformas: Windows, macOS y GNU/Linux; requiere Java Runtime según paquete.

Qué es y cómo funciona

JDownloader analiza enlaces, extrae URLs de descarga y coordina conexiones, reintentos, fragmentación y reanudación. Los módulos de hoster gestionan particularidades de servicios de alojamiento; las cuentas premium y límites dependen del proveedor externo. El motor puede ejecutarse mediante Java y se actualiza con un sistema propio.

Funciones principales

Gestión de enlaces, descarga por lotes, reanudación, extracción de archivos, reconocimiento de captchas compatibles, gestión de cuentas, listas de espera, Remote Control y automatización.

Instalación y configuración

Descarga desde jdownloader.org. En Windows selecciona expresamente el instalador 'optional software offers-free' si no quieres ofertas de terceros. Verifica la integridad del instalador con el hash publicado. Revisa los enlaces capturados antes de iniciar descargas y configura límites de conexiones y ancho de banda.

Compatibilidad y estado

Windows, macOS y GNU/Linux; requiere Java Runtime según paquete.

JDownloader 2 es gratuito y el sitio oficial ofrece un instalador Windows sin ofertas adicionales, actualizado el 4 de septiembre de 2026.

Licencia y distribución

Software gratuito de distribución propietaria con componentes open source. El instalador de Windows puede ofrecer software de terceros opcional; existe un instalador oficial sin ofertas adicionales.

Seguridad, privacidad y limitaciones

El instalador normal de Windows puede mostrar ofertas de software opcional; desmarca todas si no las necesitas o utiliza el paquete sin ofertas. Las cuentas de hosters y contraseñas se almacenan en la aplicación; protege el perfil. Descarga solo contenido autorizado y evita plugins o scripts de terceros no confiables.
