Productividad, organización y oficina

Joplin

Aplicación de notas y tareas con organización en libretas, etiquetas, búsqueda y contenido Markdown, con sincronización entre dispositivos.

Público objetivo: Personas que quieren una base de notas portátil, organizada y disponible sin conexión.

Plataformas: Windows, macOS, GNU/Linux, Android e iOS; Web Clipper para navegadores compatibles.

Qué es y cómo funciona

Aplicación de notas y tareas con organización en libretas, etiquetas, búsqueda y contenido Markdown, con sincronización entre dispositivos.

Las notas se almacenan localmente y se representan en Markdown con recursos adjuntos. El motor de sincronización intercambia cambios con un destino configurado; la aplicación puede cifrar de extremo a extremo los datos sincronizados.

Funciones principales

Libretas, etiquetas, tareas, búsqueda de texto, adjuntos, importación/exportación, complementos, Web Clipper y sincronización con distintos destinos compatibles.

Instalación y primera configuración

Instala la aplicación oficial en cada dispositivo. Crea libretas y notas; elige un destino de sincronización y configura el mismo en el resto de equipos. Si activas cifrado de extremo a extremo, conserva de forma segura la contraseña y verifica la sincronización inicial.

Compatibilidad y estado de mantenimiento

Windows, macOS, GNU/Linux, Android e iOS; Web Clipper para navegadores compatibles.

Consulta las releases oficiales para la versión estable vigente.

Los requisitos detallados dependen del sistema, arquitectura y paquete descargado. Consulta la documentación de la versión elegida antes de desplegarla en varios equipos.

Licencia y distribución

Software libre y de código abierto; Joplin Cloud es un servicio opcional de pago, no un requisito para usar la aplicación.

Seguridad, privacidad y limitaciones

Offline-first no significa que exista una copia de seguridad automática. La sincronización replica cambios y borrados; configura además una copia independiente. El cifrado E2EE requiere gestionar correctamente la clave y esperar a que los dispositivos terminen de sincronizar.
