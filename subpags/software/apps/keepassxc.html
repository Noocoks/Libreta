Navegación, privacidad y credenciales

KeePassXC

Gestor de contraseñas libre y multiplataforma que almacena credenciales en una base de datos local cifrada y compatible con el formato KDBX.

Público objetivo: Usuarios que quieren gestionar contraseñas localmente sin depender de un servicio cloud propietario.

Plataformas: Windows, macOS y GNU/Linux.

Qué es y cómo funciona

KeePassXC guarda entradas y grupos en archivos KDBX cifrados. La base utiliza cifrado como AES-256, ChaCha20 o Twofish y funciones de derivación de claves para dificultar ataques offline. La sincronización no forma parte del núcleo: el usuario puede guardar el archivo en una carpeta compartida o sincronizarlo con su servicio de almacenamiento. Browser Integration conecta extensiones mediante Native Messaging.

Funciones principales

Bóvedas KDBX, generador de contraseñas, TOTP, passkeys mediante navegador, Auto-Type, integración con extensiones, historial, adjuntos, KeeShare, SSH Agent y CLI.

Instalación y configuración

Descarga desde keepassxc.org. Crea una base KDBX con una contraseña maestra larga y considera una clave de archivo o dispositivo hardware. Guarda copias de seguridad cifradas y configura sincronización externa si la necesitas. Activa Browser Integration solo en navegadores de confianza y aprueba cada asociación.

Compatibilidad y estado

Windows, macOS y GNU/Linux.

Verificación editorial 28-11-2026. KeePassXC utiliza KDBX 3.1 y KDBX 4; KDBX 2 puede abrirse y convertirse. No admite plugins de KeePass 2.

Licencia y distribución

GPL-3.0; gratuito, open source, sin anuncios ni suscripción.

Seguridad, privacidad y limitaciones

La seguridad depende de la contraseña maestra, el KDF, la protección del dispositivo y las copias de seguridad. Si pierdes la contraseña y no tienes recuperación, la base no puede abrirse. No compartas la base sin cifrado ni almacenes la clave de archivo junto a ella. Los favicons son una función de red opcional; el proyecto no accede a recursos de red sin consentimiento explícito.
