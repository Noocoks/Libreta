Captura, streaming y comunicación audiovisual

Lightshot

Herramienta sencilla de captura de pantalla para Windows y macOS que permite seleccionar una región, anotar la imagen y compartirla mediante un enlace.

Público objetivo: Usuarios que necesitan capturas rápidas y anotaciones básicas.

Plataformas: Windows, macOS y extensiones para navegadores compatibles.

Qué es y cómo funciona

Lightshot captura una región del escritorio, abre un editor ligero para añadir texto, líneas y formas y permite guardar la imagen localmente o subirla al servicio de Lightshot para obtener un enlace. La aplicación de escritorio y las extensiones de navegador tienen flujos diferentes.

Funciones principales

Captura de región, anotaciones, guardado local, copia al portapapeles, subida a la nube y búsqueda de imágenes similares según el servicio.

Instalación y configuración

Descarga desde lightshot.co/en/download.html. Configura el atajo de captura y el destino local. Si compartes mediante URL, comprueba la imagen publicada y evita usar la subida para documentos sensibles.

Compatibilidad y estado

Windows, macOS y extensiones para navegadores compatibles.

Verificación editorial 28-11-2026. La web oficial ofrece instaladores para Windows y macOS; Linux no tiene aplicación nativa oficial.

Licencia y distribución

Freeware propietario gratuito; el servicio de alojamiento y las funciones de compartir tienen condiciones propias.

Seguridad, privacidad y limitaciones

Las capturas subidas a un servicio de terceros pueden quedar accesibles mediante enlace y pueden ser indexadas o compartidas. No subas contraseñas, documentos privados, información médica o datos de trabajo. Para contenido sensible utiliza guardado local y controla permisos del archivo.
