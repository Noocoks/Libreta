Hardware, diagnóstico y periféricos

LittleBigMouse

Herramienta para mejorar el movimiento del cursor entre monitores con distintas resoluciones y escalas DPI, ajustando la geometría lógica del escritorio.

Público objetivo: Usuarios con configuraciones de varios monitores y escalas DPI diferentes.

Plataformas: Windows 10 y Windows 11. Existe un port Linux experimental, no equivalente a la versión Windows estable.

Qué es y cómo funciona

LittleBigMouse modela la geometría de cada pantalla y ajusta la transición del puntero entre monitores con densidades y tamaños distintos. El motor aplica una configuración de bordes y coordenadas para evitar saltos verticales u horizontales al cruzar pantallas. La versión actual usa un daemon Rust y una interfaz Avalonia.

Funciones principales

Alineación lógica de monitores, transición de cursor entre DPI diferentes, screen looping, resistencia de bordes, ajuste de tamaños relativos, perfiles y rescate del cursor.

Instalación y configuración

Descarga desde littlebigmouse.mgth.fr o el repositorio oficial. La versión 5.6.0 requiere .NET 10 Runtime x64. Configura la disposición de monitores, revisa el resultado y aplica el diseño; utiliza el atajo de rescate Ctrl+Alt+Shift+M si el cursor queda atrapado (configurable en opciones).

Compatibilidad y estado

Windows 10 y Windows 11. Existe un port Linux experimental, no equivalente a la versión Windows estable.

LittleBigMouse 5.6.0 publicado según el repositorio oficial; requiere .NET 10 Runtime x64. La versión Linux está marcada como experimental.

Licencia y distribución

GPL-3.0; gratuito y de código abierto.

Seguridad, privacidad y limitaciones

El motor intercepta y gestiona eventos del ratón, por lo que requiere permisos de entrada y puede interactuar con drivers o servicios del sistema. En Linux el proyecto es experimental y necesita acceso a `/dev/input` y `/dev/uinput`; pertenecer al grupo `input` permite a procesos leer eventos de teclado/ratón, por lo que no debe hacerse sin comprender el impacto.
