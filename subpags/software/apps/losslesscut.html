Vídeo, edición y posproducción

LosslessCut

Editor rápido de vídeo y audio que corta, divide y extrae segmentos sin recodificar los flujos compatibles, conservando la calidad original.

Público objetivo: Usuarios que recortan grabaciones, eliminan segmentos o separan pistas sin editar efectos complejos.

Plataformas: Windows 10/11, macOS 13+ y GNU/Linux.

Qué es y cómo funciona

LosslessCut utiliza FFmpeg y copia los paquetes de audio/vídeo del contenedor sin volver a codificar cuando los puntos de corte y códecs lo permiten. Esto evita pérdida generacional y reduce el tiempo de proceso. Los cortes pueden ajustarse a keyframes o requerir recodificación en operaciones no compatibles.

Funciones principales

Corte sin recodificación, extracción de segmentos, selección de pistas, edición de metadatos, rotación por flag, exportación de segmentos, extracción de fotogramas y concatenación de segmentos compatibles.

Instalación y configuración

Descarga desde losslesscut.app o el repositorio oficial. Abre un archivo, marca segmentos y selecciona las pistas que quieras conservar. Comprueba los keyframes y el formato de salida; si necesitas efectos, recorte de imagen, transiciones o mezcla de audio, utiliza un editor que recodifique como Kdenlive o DaVinci Resolve.

Compatibilidad y estado

Windows 10/11, macOS 13+ y GNU/Linux.

LosslessCut 3.70.2 publicado el 28 de octubre de 2026. El proyecto declara que las builds de GitHub pueden ser experimentales frente a las versiones de tienda.

Licencia y distribución

MIT; gratuito y de código abierto. Las versiones de Microsoft Store y Mac App Store son de pago para financiar el desarrollo y ofrecer instaladores firmados/actualizaciones automáticas.

Seguridad, privacidad y limitaciones

Las builds de GitHub no están firmadas en Windows y pueden generar avisos de SmartScreen; verifica que proceden del repositorio oficial. Las releases de GitHub pueden contener funciones nuevas no probadas; el autor las considera beta pública. No utilices LosslessCut para operaciones que requieren reencodificación.
