Personalización y escritorio

Nilesoft Shell

Extensión de menú contextual para el Explorador de archivos de Windows que permite añadir comandos, submenús, filtros y acciones personalizadas.

Público objetivo: Usuarios avanzados que quieren adaptar el menú contextual de Windows.

Plataformas: Windows 7, 8, 10 y 11; x86, x64 y ARM64 según la web oficial.

Qué es y cómo funciona

Shell amplía el menú contextual de Windows y carga su configuración desde archivos de texto `shell.nss`. La configuración define elementos, submenús, separadores, expresiones, variables y acciones. Puede añadir, modificar o retirar elementos que aparecen al pulsar con el botón derecho sobre archivos, carpetas, escritorio y barra de tareas.

Funciones principales

Menús y submenús personalizados, comandos, accesos a archivos/carpetas/URLs, expresiones, variables, iconos SVG/PNG/ICO, filtros, búsqueda y varias columnas.

Instalación y configuración

Descarga desde nilesoft.org o el repositorio oficial. Extrae el paquete, ejecuta el instalador o la modalidad portable según la release y revisa el archivo `shell.nss`. Empieza con un menú de prueba y añade comandos de uno en uno; consulta la documentación de la sintaxis antes de importar configuraciones ajenas.

Compatibilidad y estado

Windows 7, 8, 10 y 11; x86, x64 y ARM64 según la web oficial.

Verificación editorial 28-11-2026. La web oficial declara compatibilidad con Windows 7/8/10/11 y arquitecturas x86/x64/ARM64.

Licencia y distribución

MIT; gratuito, portable y de código abierto.

Seguridad, privacidad y limitaciones

Las acciones del menú ejecutan comandos con los permisos del usuario actual. Una configuración descargada puede lanzar PowerShell, scripts o programas externos. Revisa cada acción antes de añadirla y evita elevar el proceso sin necesidad. Haz copia de `shell.nss` antes de cambiar configuraciones complejas.
