Desarrollo y herramientas para programadores

Notepad++

Editor de texto y código fuente para Windows con resaltado de sintaxis, plegado de código, pestañas, búsqueda avanzada y sistema de plugins.

Público objetivo: Desarrolladores, administradores y usuarios que editan texto plano, scripts y código.

Plataformas: Windows; builds x86, x64 y ARM64. No existe versión oficial nativa para macOS o Linux.

Qué es y cómo funciona

Notepad++ utiliza Scintilla como componente de edición y Lexilla/definiciones de lenguaje para coloreado y plegado de sintaxis. El sistema de plugins amplía funciones mediante DLLs cargadas por la aplicación. La configuración, sesiones, macros y preferencias se almacenan localmente y pueden gestionarse en modo portable.

Funciones principales

Edición por pestañas, resaltado de unos 80 lenguajes, plegado, búsqueda/reemplazo con expresiones regulares, macros, comparación mediante plugins, auto-completado, edición multi-cursor y Plugin Admin.

Instalación y configuración

Descarga desde notepad-plus-plus.org y selecciona la arquitectura correcta. El instalador permite integrar el menú contextual y asociar extensiones. Usa Plugin Admin para instalar complementos y exporta la configuración si necesitas migrar entre equipos. También existe un paquete portable.

Compatibilidad y estado

Windows; builds x86, x64 y ARM64. No existe versión oficial nativa para macOS o Linux.

Verificación editorial 28-11-2026. La documentación oficial indica compatibilidad con los sistemas Windows que Microsoft mantiene y ofrece paquetes x86/x64/ARM64.

Licencia y distribución

GPL-3.0-or-later; software libre y gratuito.

Seguridad, privacidad y limitaciones

Los plugins son código ejecutable dentro del proceso de Notepad++; instala solo desde Plugin Admin o repositorios oficiales y comprueba su mantenimiento. No abras archivos desconocidos con macros o scripts externos asociados. El proyecto publica una clave GPG para verificar releases; valida la firma o hash cuando esté disponible.
