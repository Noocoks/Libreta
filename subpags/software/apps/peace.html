Audio, música y producción

Peace Equalizer

Interfaz gráfica para Equalizer APO en Windows que permite configurar ecualización paramétrica, filtros, efectos y perfiles de audio.

Público objetivo: Usuarios que ajustan la respuesta de auriculares, altavoces y dispositivos de audio en Windows.

Plataformas: Windows 7 a Windows 11; requiere Equalizer APO 0.9.1 o posterior.

Qué es y cómo funciona

Peace no procesa audio por sí mismo: escribe configuraciones para Equalizer APO, que se integra en la cadena de audio de Windows. Equalizer APO aplica filtros y procesamiento a los dispositivos seleccionados; Peace proporciona controles gráficos, presets, curvas, reglas y efectos.

Funciones principales

Ecualizador gráfico y paramétrico, hasta 31 bandas por canal, preamp, filtros peak/shelf/pass/notch, crossfeed, delay, bass boost, virtual surround, reverb, AutoEQ, hotkeys y perfiles por dispositivo o programa.

Instalación y configuración

Instala primero Equalizer APO 0.9.1 o posterior y selecciona el dispositivo de reproducción o captura en Configurator. Después descarga PeaceSetup.exe desde el proyecto oficial de SourceForge y permite que añada su configuración a `config.txt`. Ajusta el preamp antes de aplicar boosts para evitar clipping.

Compatibilidad y estado

Windows 7 a Windows 11; requiere Equalizer APO 0.9.1 o posterior.

Verificación editorial 28-11-2026. Peace es una interfaz para Equalizer APO y no sustituye al motor de procesamiento.

Licencia y distribución

Software gratuito; el código y los componentes se distribuyen bajo las licencias indicadas en el repositorio. No requiere suscripción.

Seguridad, privacidad y limitaciones

Descarga el instalador firmado desde el SourceForge oficial; el autor advierte de sitios que copian el nombre y empaquetan software no deseado. Si Windows cambia el driver de audio y deja de aplicar la curva, vuelve a ejecutar Configurator y selecciona el dispositivo correcto.
