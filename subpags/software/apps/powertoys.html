Productividad, organización y oficina

Microsoft PowerToys

Colección de utilidades gratuitas y open source de Microsoft para ampliar la productividad, personalización y administración de Windows.

Público objetivo: Usuarios avanzados, desarrolladores y administradores que quieren funciones adicionales en Windows.

Plataformas: Windows 11 o Windows 10 versión 2004 (build 19041) o posterior; procesador x64 o ARM64 y WebView2 Runtime.

Qué es y cómo funciona

PowerToys agrupa herramientas independientes que se integran con la shell y el escritorio de Windows. Algunas se ejecutan como procesos residentes, otras añaden extensiones del Explorador o interceptan atajos de teclado. Cada módulo tiene su propia configuración y requisitos; el proyecto se desarrolla públicamente en GitHub.

Funciones principales

FancyZones, PowerRename, Keyboard Manager, PowerToys Run/Command Palette, Awake, Color Picker, Image Resizer, File Locksmith, Always on Top, Peek y otras utilidades según la versión.

Instalación y configuración

Instala desde Microsoft Store, GitHub Releases o WinGet (`winget install --id Microsoft.PowerToys --source winget`). Abre Settings y activa solo los módulos que necesites. Revisa los atajos globales para evitar conflictos con aplicaciones y juegos.

Compatibilidad y estado

Windows 11 o Windows 10 versión 2004 (build 19041) o posterior; procesador x64 o ARM64 y WebView2 Runtime.

Verificación editorial 28-11-2026. Los requisitos oficiales indican Windows 10 build 19041+ o Windows 11, x64/ARM64 y WebView2 Runtime.

Licencia y distribución

MIT; gratuito y de código abierto.

Seguridad, privacidad y limitaciones

PowerToys registra datos básicos de diagnóstico/telemetría según la documentación del proyecto; revisa los controles de privacidad disponibles. Algunas utilidades necesitan privilegios elevados para interactuar con procesos o modificar archivos. Descarga desde Microsoft o el repositorio oficial y mantén la aplicación actualizada.
