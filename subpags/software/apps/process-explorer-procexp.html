Administración y mantenimiento del sistema

Process Explorer (Procexp)

Administrador avanzado de procesos de Sysinternals que muestra jerarquías, propietarios, handles, DLL cargadas y archivos mapeados por cada proceso.

Público objetivo: Técnicos y administradores que investigan procesos, bloqueos de archivos, fugas de handles y problemas de DLL.

Plataformas: Windows 11 y versiones cliente posteriores; Windows Server 2019 y posteriores según la documentación actual.

Qué es y cómo funciona

Process Explorer combina enumeración de procesos con consultas de handles y módulos cargados. La ventana superior presenta procesos activos y sus relaciones; la inferior muestra handles abiertos o DLL y archivos mapeados del proceso seleccionado. La búsqueda permite localizar qué proceso mantiene abierto un archivo o qué proceso ha cargado un módulo.

Funciones principales

Árbol de procesos, propietario, handles, DLL, archivos mapeados, búsqueda de handles y módulos, información de rendimiento y diagnóstico de procesos.

Instalación y configuración

Descarga desde Microsoft Sysinternals y ejecuta `procexp.exe`; no requiere instalación tradicional. Usa la vista de árbol para localizar procesos y cambia la ventana inferior entre Handle y DLL. Eleva privilegios solo cuando necesites inspeccionar procesos protegidos y comprende los efectos antes de finalizar un proceso.

Compatibilidad y estado

Windows 11 y versiones cliente posteriores; Windows Server 2019 y posteriores según la documentación actual.

Process Explorer v17.21 publicado el 5 de noviembre de 2026 según Microsoft Sysinternals.

Licencia y distribución

Freeware de Microsoft Sysinternals; gratuita y propietaria.

Seguridad, privacidad y limitaciones

Finalizar un proceso puede provocar pérdida de datos o detener servicios. No cierres procesos del sistema por su nombre sin investigar ruta, firma, propietario y dependencias. Los volcados y detalles de procesos pueden contener datos sensibles; protégelos al compartirlos.
