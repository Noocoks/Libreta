Descargas y medios de instalación

qBittorrent

Cliente BitTorrent libre y multiplataforma para descargar y compartir archivos mediante torrents y enlaces magnet.

Público objetivo: Usuarios que gestionan transferencias P2P y distribuciones de archivos legítimas.

Plataformas: Windows 10+, GNU/Linux, macOS y FreeBSD; la compatibilidad exacta depende del paquete.

Qué es y cómo funciona

qBittorrent utiliza libtorrent-rasterbar para implementar el protocolo BitTorrent y Qt para la interfaz. Participa en enjambres P2P mediante trackers, DHT, Peer Exchange y Local Peer Discovery; los enlaces magnet permiten localizar metadatos sin descargar primero un archivo .torrent. El Web UI ofrece control remoto mediante HTTP.

Funciones principales

Descargas torrent y magnet, DHT, PEX, LSD, torrents privados, RSS con filtros, cola y prioridades, selección de archivos, planificador de ancho de banda, creación de torrents, filtros IP y Web UI.

Instalación y configuración

Descarga desde qbittorrent.org y verifica firma PGP o SHA-256 cuando esté disponible. Configura una carpeta de descargas, límites de subida/bajada y un puerto entrante. Si habilitas Web UI, usa contraseña robusta y limita el acceso a localhost o a una LAN de confianza.

Compatibilidad y estado

Windows 10+, GNU/Linux, macOS y FreeBSD; la compatibilidad exacta depende del paquete.

qBittorrent v5.3.1 aparece como versión más reciente en la web oficial consultada. El proyecto declara que no incluye anuncios.

Licencia y distribución

GPL-2.0-or-later; gratuito, open source y sin publicidad integrada.

Seguridad, privacidad y limitaciones

El tráfico P2P expone la IP pública a los pares del enjambre. Descarga únicamente contenido que tengas derecho a obtener y revisa archivos antes de ejecutarlos. No expongas Web UI a Internet sin HTTPS, autenticación y restricciones de acceso. Evita paquetes de terceros no oficiales.
