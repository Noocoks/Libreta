Archivos, compresión y gestión documental

QuickLook

Herramienta para Windows que muestra una vista previa rápida de archivos al pulsar la barra espaciadora, sin abrir la aplicación asociada.

Público objetivo: Usuarios que revisan muchas imágenes, documentos, vídeos y archivos desde el Explorador.

Plataformas: Windows; consulta los requisitos de la release para la versión exacta.

Qué es y cómo funciona

QuickLook registra una combinación de teclado para mostrar un panel de previsualización asociado al archivo seleccionado. Los formatos se gestionan mediante plugins y componentes específicos, de modo que la aplicación anfitriona puede delegar la representación de documentos, imágenes, audio o vídeo.

Funciones principales

Vista previa con la barra espaciadora, navegación entre archivos, previsualización de formatos comunes y ampliación mediante plugins para formatos adicionales.

Instalación y configuración

Instala desde Microsoft Store o desde las releases del repositorio oficial. Selecciona un archivo en el Explorador y pulsa Espacio; vuelve a pulsar Espacio o Esc para cerrar. Añade plugins únicamente desde las fuentes oficiales y reinicia QuickLook cuando lo requiera el complemento.

Compatibilidad y estado

Windows; consulta los requisitos de la release para la versión exacta.

Proyecto de código abierto activo; las versiones y formatos compatibles se publican en el repositorio oficial.

Licencia y distribución

GPL-3.0; gratuito y de código abierto.

Seguridad, privacidad y limitaciones

Los plugins amplían el código que procesa archivos y pueden introducir vulnerabilidades. No instales plugins de fuentes desconocidas y mantén QuickLook actualizado. Los formatos soportados varían por plugin y versión; consulta SUPPORTED_FORMATS.md antes de depender de una extensión concreta.
