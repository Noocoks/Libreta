Administración y mantenimiento del sistema

RAMMap

Herramienta Sysinternals para analizar cómo Windows asigna la memoria física, las páginas en espera, la caché de archivos y el uso de memoria por procesos y controladores.

Público objetivo: Administradores y usuarios avanzados que diagnostican consumo de RAM y comportamiento de la memoria de Windows.

Plataformas: Windows Vista y versiones posteriores según la documentación de Microsoft.

Qué es y cómo funciona

RAMMap consulta estructuras y contadores de memoria del sistema y clasifica las páginas físicas según su uso. No se limita a mostrar la memoria privada de los procesos: permite distinguir listas de páginas, caché de archivos, memoria del kernel, drivers, standby list y otros tipos de asignación.

Funciones principales

Use Counts, Processes, Priority Summary, Physical Pages, Physical Ranges, File Summary y File Details; captura y comparación de estados de memoria.

Instalación y configuración

Descarga desde Microsoft Sysinternals y ejecuta `RAMMap.exe`. Espera a que termine el análisis y revisa primero Use Counts y File Summary. Compara capturas en condiciones similares y utiliza la pestaña Processes para relacionar consumo con procesos.

Compatibilidad y estado

Windows Vista y versiones posteriores según la documentación de Microsoft.

RAMMap v1.63 publicado el 26 de marzo de 2026 según Microsoft Learn. Verificación editorial 28-11-2026.

Licencia y distribución

Freeware de Microsoft Sysinternals; gratuita y propietaria.

Seguridad, privacidad y limitaciones

RAMMap es una herramienta de diagnóstico, no un optimizador de memoria. Vaciar listas de espera o ejecutar operaciones de limpieza cambia temporalmente el comportamiento de caché y puede empeorar el rendimiento; no lo uses como rutina para liberar RAM. Interpreta las métricas teniendo en cuenta que Windows usa memoria libre como caché.
