Descargas y medios de instalación

Rufus

Utilidad portable para formatear unidades USB y crear medios de arranque BIOS/UEFI a partir de imágenes ISO y otros formatos.

Público objetivo: Técnicos y usuarios que preparan instaladores de Windows/Linux, herramientas de diagnóstico y medios de rescate.

Plataformas: Windows 8 o posterior; la aplicación dispone de builds x86, x64 y ARM64.

Qué es y cómo funciona

Rufus particiona y formatea la unidad seleccionada y escribe una imagen de arranque adaptando el esquema de partición, sistema de archivos y modo de destino. Puede preparar medios UEFI:NTFS, descargar ISOs oficiales de Microsoft y validar medios UEFI. El modo de instalación y la compatibilidad dependen de la ISO y del firmware.

Funciones principales

Formateo FAT/FAT32/NTFS/exFAT/UDF/ReFS, medios DOS, BIOS/UEFI, ISOs de Windows/Linux, Windows To Go, persistencia Linux, descarga de ISOs, verificación de bloques defectuosos y validación UEFI.

Instalación y configuración

Descarga desde rufus.ie o el repositorio oficial. Selecciona cuidadosamente el dispositivo, la imagen ISO, el esquema de partición (GPT/MBR) y el sistema destino. Comprueba el registro de Rufus y verifica el dispositivo seleccionado antes de pulsar Start.

Compatibilidad y estado

Windows 8 o posterior; la aplicación dispone de builds x86, x64 y ARM64.

Rufus 4.15 publicado el 30 de junio de 2026 en la web oficial consultada. No requiere instalación y es compatible con Secure Boot según el proyecto.

Licencia y distribución

GPL-3.0-or-later; software libre, gratuito y portable.

Seguridad, privacidad y limitaciones

La operación destruye particiones y datos del USB seleccionado. Rufus muestra advertencias explícitas; no las ignores. Seleccionar GPT/UEFI o MBR/BIOS cambia la compatibilidad del medio. Descarga ISOs de fuentes oficiales y verifica hashes cuando el proveedor los publique.
