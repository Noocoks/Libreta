Redes, transferencia y acceso remoto

RustDesk

Software de escritorio remoto multiplataforma con conexiones P2P cifradas y opción de utilizar infraestructura propia de ID y relay.

Público objetivo: Usuarios, técnicos y administradores que necesitan asistencia remota o acceso a equipos propios.

Plataformas: Windows, macOS, GNU/Linux, Android, iOS y Web; funciones según cliente y versión.

Qué es y cómo funciona

El cliente contacta con un servidor de rendezvous `hbbs` para localizar al equipo remoto e intentar una conexión P2P mediante NAT traversal. Si la conexión directa falla, el tráfico puede pasar por un relay `hbbr`. La documentación del proyecto describe cifrado de extremo a extremo basado en NaCl. El servidor OSS permite controlar la infraestructura de identificación y relay.

Funciones principales

Control remoto, transferencia de archivos, portapapeles, conexiones P2P, relay, servidores propios, clientes móviles y administración centralizada en Server Pro.

Instalación y configuración

Instala el cliente desde la web o repositorio oficial. Para uso público estándar puedes utilizar la infraestructura configurada por el cliente; para autoalojar, despliega `hbbs` y `hbbr` siguiendo la guía oficial, configura DNS, firewall y puertos, y distribuye la clave pública del servidor a los clientes.

Compatibilidad y estado

Windows, macOS, GNU/Linux, Android, iOS y Web; funciones según cliente y versión.

Verificación editorial 28-11-2026. La documentación oficial diferencia el servidor OSS gratuito del Server Pro comercial.

Licencia y distribución

Cliente open source. RustDesk Server OSS es gratuito y de código abierto para autoalojamiento; RustDesk Server Pro es comercial y añade consola y gestión empresarial.

Seguridad, privacidad y limitaciones

El acceso remoto equivale a conceder control sobre el equipo. Usa contraseñas fuertes, MFA cuando esté disponible, listas de acceso y confirmación de sesiones. Si autoalojas, protege las claves del servidor, actualiza ambos servicios y no expongas interfaces de administración sin control de acceso. Verifica la identidad del equipo remoto antes de compartir pantalla o archivos.
