Redes, transferencia y acceso remoto

scrcpy

Herramienta de línea de comandos para duplicar y controlar dispositivos Android desde Windows, macOS o Linux mediante USB o TCP/IP.

Público objetivo: Desarrolladores Android, técnicos y usuarios que necesitan controlar un móvil desde el PC.

Plataformas: Windows, macOS y GNU/Linux; Android 5.0 (API 21) o posterior.

Qué es y cómo funciona

scrcpy inicia un servidor temporal en el dispositivo mediante Android Debug Bridge (ADB) y transmite vídeo y eventos de entrada al cliente de escritorio. Puede usar USB o TCP/IP. No requiere root ni instalar una aplicación persistente en Android. El cliente decodifica el vídeo y envía acciones de teclado, ratón y portapapeles.

Funciones principales

Duplicación de pantalla, control con teclado/ratón, grabación, audio forwarding en Android 11+, cámara en Android 12+, pantalla virtual, copia/pega, OTG y conexión inalámbrica mediante TCP/IP.

Instalación y configuración

Descarga únicamente desde el repositorio oficial Genymobile/scrcpy. Habilita Opciones de desarrollador y Depuración USB, conecta el dispositivo y acepta la clave RSA del PC. En Windows ejecuta el paquete oficial y sigue la guía `doc/windows.md`. Para conexión inalámbrica, establece primero ADB por USB o configura el emparejamiento TCP/IP según la versión de Android.

Compatibilidad y estado

Windows, macOS y GNU/Linux; Android 5.0 (API 21) o posterior.

La documentación oficial consultada identifica scrcpy 5.0.1 y Android API 21 como requisito mínimo. Audio forwarding requiere Android 11+ y cámara Android 12+.

Seguridad, privacidad y limitaciones

La depuración USB permite al equipo autorizado ejecutar operaciones ADB con privilegios relevantes sobre el dispositivo. Autoriza solo ordenadores de confianza y revoca autorizaciones cuando termines. No descargues builds de webs de terceros: el proyecto identifica su repositorio GitHub como única fuente oficial. Android 4.4 no cumple el requisito mínimo API 21.
