Personalización y escritorio

Seelen UI

Entorno de escritorio personalizable para Windows que combina barra de tareas alternativa, dock, lanzador, tiling window manager y paneles.

Público objetivo: Usuarios avanzados que quieren transformar de forma profunda la interfaz de Windows.

Plataformas: Windows 10 y Windows 11.

Qué es y cómo funciona

Seelen UI está construido con tecnologías web y Tauri para integrar una interfaz basada en WebView con funciones nativas de Windows. Reemplaza o complementa elementos de la shell mediante componentes como dock, barra, launcher y administrador de ventanas en mosaico. Su integración depende de WebView2 y de componentes de Windows.

Funciones principales

Dock, barra de tareas alternativa, lanzador, tiling, widgets, temas, atajos, perfiles de diseño y personalización de elementos del escritorio.

Instalación y configuración

Descarga el paquete firmado desde GitHub Releases, Microsoft Store o winget según prefieras. En Windows 10 asegúrate de que Microsoft Edge y WebView2 Runtime estén instalados; el instalador oficial incluye el runtime en su paquete exe. Prueba primero el modo de configuración por defecto y conserva una vía para volver a la shell original.

Compatibilidad y estado

Windows 10 y Windows 11.

Proyecto activo; consulta las releases oficiales y las notas de versión antes de instalar actualizaciones.

Licencia y distribución

AGPL-3.0; software libre y de código abierto.

Seguridad, privacidad y limitaciones

La aplicación modifica componentes visibles y se integra estrechamente con la shell. Una actualización o configuración incompatible puede afectar el acceso al escritorio. Usa paquetes firmados oficiales, crea un punto de restauración y no elimines Edge/WebView2 si el programa los necesita.
