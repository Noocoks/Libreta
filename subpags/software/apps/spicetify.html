Spicetify

Herramienta de línea de comandos para personalizar el cliente oficial de Spotify mediante temas CSS, extensiones y aplicaciones integradas.

Público objetivo: Usuarios avanzados de Spotify que quieren modificar la interfaz y añadir funciones no incluidas en el cliente oficial.

Plataformas: Windows, macOS y GNU/Linux; compatibilidad condicionada por la versión del cliente Spotify.

Qué es y cómo funciona

Spicetify modifica recursos del cliente de escritorio Spotify e inyecta CSS, extensiones y aplicaciones personalizadas. Mantiene una copia de respaldo de los recursos originales y aplica modificaciones mediante comandos CLI. Las actualizaciones de Spotify pueden sobrescribir archivos y requerir restaurar o volver a aplicar la personalización.

Funciones principales

Temas, CSS personalizado, extensiones JavaScript, custom apps, snippets, módulos y restauración del cliente original.

Instalación y configuración

Instala el cliente oficial de Spotify y después Spicetify desde spicetify.app o GitHub. Ejecuta `spicetify backup apply` según la guía de instalación, realiza una copia de seguridad y aplica un tema de prueba. Tras actualizar Spotify, revisa el estado del CLI y vuelve a aplicar los cambios solo cuando exista compatibilidad.

Compatibilidad y estado

Windows, macOS y GNU/Linux; compatibilidad condicionada por la versión del cliente Spotify.

Verificación editorial 28-11-2026. Spicetify CLI es multiplataforma y la organización oficial mantiene temas, módulos y documentación separados.

Licencia y distribución

LGPL-2.1 para el CLI principal; gratuito y de código abierto. Temas, extensiones y módulos pueden tener licencias distintas.

Seguridad, privacidad y limitaciones

Las extensiones y aplicaciones personalizadas pueden ejecutar JavaScript dentro del cliente y acceder a datos de la interfaz. Instala solo módulos de confianza. Los cambios no oficiales pueden romperse tras actualizaciones de Spotify y no están soportados por Spotify; conserva un método para restaurar el cliente.
