Administración y mantenimiento del sistema

System Informer

Monitor y herramienta de diagnóstico avanzada para Windows que permite inspeccionar procesos, recursos, actividad de red, servicios y detalles internos del sistema.

Público objetivo: Usuarios avanzados, desarrolladores y administradores que necesitan investigar el comportamiento de Windows.

Plataformas: Windows 10 y Windows 11, 32 y 64 bits según la página de descargas actual.

Qué es y cómo funciona

System Informer presenta una vista detallada de procesos y recursos y puede recopilar información de servicios, conexiones, actividad de disco y trazas. Algunas funciones avanzadas utilizan un controlador de kernel firmado para consultar información que no está disponible mediante APIs de usuario; la herramienta y sus componentes tienen distintos niveles de privilegio.

Funciones principales

Monitorización de procesos, recursos, red y disco; inspección de handles y módulos; control de servicios; análisis de procesos y depuración de software.

Instalación y configuración

Descarga el instalador o paquete portable desde systeminformer.com o GitHub oficial. Comprueba el SHA-256 publicado por el proyecto antes de ejecutar el paquete. Empieza sin elevar privilegios y concede elevación únicamente cuando una función lo necesite; revisa las solicitudes de instalación o carga de driver.

Compatibilidad y estado

Windows 10 y Windows 11, 32 y 64 bits según la página de descargas actual.

La página oficial consultada publica la serie 4.0.26241 y declara Windows 10/11 de 32 y 64 bits. El proyecto declara licencia MIT.

Licencia y distribución

MIT; gratuito y de código abierto.

Seguridad, privacidad y limitaciones

Es una herramienta potente con capacidad para inspeccionar y modificar procesos y servicios. Una acción equivocada puede cerrar procesos críticos o afectar al sistema. Descarga solo desde dominios oficiales listados por el proyecto, verifica el hash y no instales builds Canary en equipos de producción.
