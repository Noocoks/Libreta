Text Grab

Herramienta de OCR para Windows que permite seleccionar una región de pantalla y extraer texto mediante el motor de reconocimiento de Windows.

Público objetivo: Usuarios que copian texto desde imágenes, vídeos, documentos escaneados y aplicaciones sin selección de texto.

Plataformas: Windows 10 y Windows 11; requiere los componentes de OCR disponibles en el sistema.

Qué es y cómo funciona

Text Grab captura una región de la pantalla y utiliza Windows.Media.Ocr para reconocer caracteres en la imagen. El resultado se copia al portapapeles o se presenta para revisión. El reconocimiento se realiza mediante las APIs locales de Windows y no requiere enviar la imagen a un servicio cloud.

Funciones principales

OCR por región, extracción de texto, selección de idioma, atajos de teclado, copia al portapapeles y modos de captura rápida.

Instalación y configuración

Descarga desde el repositorio oficial de TheJoeFin/Text-Grab o Microsoft Store si está disponible. Configura el atajo de captura y comprueba que Windows tenga instalados los paquetes de idioma necesarios para el OCR.

Compatibilidad y estado

Windows 10 y Windows 11; requiere los componentes de OCR disponibles en el sistema.

Verificación editorial 28-11-2026. Text Grab utiliza Windows OCR y está orientado a Windows 10/11.

Licencia y distribución

MIT; gratuito y de código abierto.

Seguridad, privacidad y limitaciones

La captura puede contener información privada; revisa el texto extraído antes de pegarlo en otra aplicación. La precisión depende de resolución, contraste, idioma y fuente. El motor local de Windows no garantiza reconocimiento perfecto ni conserva formato complejo.
