Personalización y escritorio

TranslucentTB

Utilidad ligera que modifica el fondo de la barra de tareas de Windows con transparencia, tintes, desenfoque y efectos acrílicos.

Público objetivo: Usuarios de Windows 10/11 que personalizan la barra de tareas.

Plataformas: Windows 10 versión 1903 o posterior y Windows 11; x64 y ARM64. No existe versión de 32 bits.

Qué es y cómo funciona

TranslucentTB se ejecuta en segundo plano desde el área de notificación y cambia la apariencia del fondo de la taskbar usando APIs y comportamientos específicos de Windows. Mantiene estados visuales y puede seleccionar uno dinámicamente según la ventana activa, el menú Inicio, la búsqueda o Task View.

Funciones principales

Estados Normal, Opaque, Clear, Blur y Acrylic; selector de color con alfa; modos dinámicos según ventana visible/maximizada y menús del sistema; configuración y arranque con Windows.

Instalación y configuración

Instala desde Microsoft Store o desde los paquetes firmados del repositorio oficial. Abre el icono del área de notificación, selecciona el estado visual y configura modos dinámicos. La versión portable se distribuye como ZIP y la documentación indica que esa variante solo funciona en Windows 11.

Compatibilidad y estado

Windows 10 versión 1903 o posterior y Windows 11; x64 y ARM64. No existe versión de 32 bits.

2026.2, publicada el 31 de agosto de 2026. El 25 de noviembre de 2026 se documentó un fallo en builds recientes de Windows 11 25H2/26H2 tras KB5132057; la corrección estaba pendiente de una publicación firmada.

Licencia y distribución

GPL-3.0; gratuito y de código abierto.

Seguridad, privacidad y limitaciones

Descarga únicamente desde Microsoft Store o el repositorio oficial. El proyecto advierte que las builds de desarrollo pueden estar incompletas. En las builds de Windows 11 afectadas por KB5132057 la aplicación puede ejecutarse pero no aplicar cambios; no fuerces modificaciones del sistema para solucionar un fallo de compatibilidad.
