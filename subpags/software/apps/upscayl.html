Diseño, ilustración y creación visual

Upscayl

Aplicación open source de ampliación y mejora de imágenes mediante modelos de super-resolución, con procesamiento local acelerado por GPU Vulkan.

Público objetivo: Diseñadores, fotógrafos y usuarios que amplían imágenes pequeñas o de baja resolución.

Plataformas: Windows 10+, macOS 12+ y GNU/Linux; requiere GPU compatible con Vulkan para la ruta de aceleración habitual.

Qué es y cómo funciona

Upscayl utiliza modelos de super-resolución basados en Real-ESRGAN y NCNN/Vulkan para inferir detalles plausibles al ampliar una imagen. El proceso no recupera información real perdida: genera una estimación a partir del modelo. Puede procesar lotes y utilizar modelos diferentes según el contenido.

Funciones principales

Ampliación de imagen, modelos Real-ESRGAN, procesamiento por lotes, presets, escalado x2/x4, mejora de nitidez y CLI mediante upscayl-ncnn.

Instalación y configuración

Descarga desde upscayl.org o GitHub Releases. Comprueba que la GPU sea compatible con Vulkan; algunas iGPU no funcionan con el backend habitual. Selecciona modelo y escala, realiza una prueba con una imagen representativa y compara con el original antes de procesar lotes.

Compatibilidad y estado

Windows 10+, macOS 12+ y GNU/Linux; requiere GPU compatible con Vulkan para la ruta de aceleración habitual.

Upscayl 2.15 aparece como release más reciente en el repositorio oficial consultado. Requiere Windows 10+, macOS 12+ o Linux y GPU Vulkan compatible.

Licencia y distribución

AGPL-3.0 para la aplicación y backend open source; gratuito.

Seguridad, privacidad y limitaciones

El modelo puede inventar texturas y detalles; no utilices el resultado como evidencia forense ni para verificar identidad o contenido de una imagen. El procesamiento es local en la aplicación de escritorio; utiliza modelos personalizados solo desde fuentes confiables.
