Desarrollo y herramientas para programadores

Visual Studio Code

Editor de código extensible de Microsoft con IntelliSense, depuración, terminal integrada, control de versiones y un ecosistema de extensiones.

Público objetivo: Desarrolladores web, software, scripting y usuarios que necesitan un editor ligero y extensible.

Plataformas: Windows, macOS y GNU/Linux; builds x64, ARM64 y según plataforma.

Qué es y cómo funciona

VS Code se basa en Code-OSS, Electron y Monaco Editor. Extensiones añaden lenguajes, depuradores, herramientas de desarrollo remoto y conexiones a servicios. La distribución oficial integra Microsoft Marketplace, telemetría y componentes propios que no forman parte íntegra de la build open source.

Funciones principales

IntelliSense, depuración, terminal integrada, Git, tareas, snippets, Remote Development, Dev Containers, Live Share y extensiones del Marketplace.

Instalación y configuración

Descarga desde code.visualstudio.com. Instala solo extensiones necesarias y revisa sus publishers y permisos. Configura perfiles por proyecto, sincronización si la necesitas y settings.json bajo control de versiones. Para entornos PHP/JS instala runtimes y herramientas externas por separado.

Compatibilidad y estado

Windows, macOS y GNU/Linux; builds x64, ARM64 y según plataforma.

Verificación editorial 28-11-2026. Microsoft mantiene builds para Windows, macOS y Linux; el código fuente Code-OSS está bajo MIT, pero el producto oficial usa licencia Microsoft.

Licencia y distribución

La distribución oficial de Visual Studio Code es gratuita pero propietaria y utiliza la licencia de Microsoft. El repositorio Code-OSS está bajo MIT; no debe confundirse la distribución de Microsoft con una build OSS como VSCodium.

Seguridad, privacidad y limitaciones

Las extensiones pueden ejecutar código, acceder a archivos y conectarse a servicios. Confía en publishers verificados y revisa permisos. La distribución oficial recopila telemetría y datos de uso según la configuración y política de Microsoft; puedes desactivar experiencias y datos opcionales desde Settings. Para una distribución comunitaria sin branding/telemetría Microsoft, evalúa VSCodium, teniendo en cuenta que su marketplace difiere.
