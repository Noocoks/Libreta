Audio, música y producción

Voicemeeter

Mezclador de audio virtual para Windows que combina entradas físicas y aplicaciones, enruta señales a salidas y crea dispositivos virtuales de entrada/salida.

Público objetivo: Streamers, creadores, músicos y usuarios que enrutan audio entre aplicaciones y dispositivos.

Plataformas: Windows XP a Windows 11; builds x86/x64 y ARM64 según la versión.

Qué es y cómo funciona

Voicemeeter instala dispositivos de audio virtuales que aparecen en Windows como endpoints de entrada/salida. Su mezclador combina fuentes físicas (WDM, KS, MME, ASIO) y aplicaciones, permite buses virtuales y envía la mezcla a dispositivos hardware o software. Banana y Potato amplían canales, buses y procesamiento.

Funciones principales

Mezcla de micrófonos, aplicaciones y entradas físicas, buses virtuales, EQ, compresor, gate, efectos, ASIO, MME, WDM, KS, VBAN y perfiles de enrutamiento.

Instalación y configuración

Descarga el paquete desde VB-Audio. Ejecuta Setup como administrador y reinicia Windows después de instalar o desinstalar el driver virtual. Empieza con Voicemeeter Standard y configura Windows para enviar cada aplicación al dispositivo virtual correcto; consulta el manual paso a paso, especialmente el apartado inicial.

Compatibilidad y estado

Windows XP a Windows 11; builds x86/x64 y ARM64 según la versión.

Voicemeeter Standard 1.1.3.0 publicado en septiembre de 2026; el proveedor declara soporte desde XP hasta Windows 11 y ARM64.

Licencia y distribución

Donationware de VB-Audio. La aplicación es gratuita para usar con todas las funciones disponibles (excepto opcionales), pero el uso profesional en empresas, instituciones u organizaciones requiere licencia según las condiciones del proveedor.

Seguridad, privacidad y limitaciones

La instalación añade drivers virtuales de audio y puede cambiar dispositivos predeterminados. Guarda una configuración de audio previa y verifica entradas/salidas después de reiniciar. En contextos profesionales revisa la licencia: el proveedor exige licencias en organizaciones donde los usuarios no pueden identificar o apoyar individualmente el software.
