VSCodium

Distribución comunitaria de binarios de Visual Studio Code construida desde el código fuente de VS Code, con configuración libre de la marca y telemetría de Microsoft.

Público objetivo: Desarrolladores que desean el ecosistema de VS Code con una distribución comunitaria y ajustes de telemetría distintos.

Plataformas: Windows 10 o posterior, macOS 12 o posterior y GNU/Linux; x64 y ARM64, además de otros targets Linux publicados.

Qué es y cómo funciona

Distribución comunitaria de binarios de Visual Studio Code construida desde el código fuente de VS Code, con configuración libre de la marca y telemetría de Microsoft.

VSCodium es un editor basado en el proyecto VS Code y Electron. El repositorio mantiene scripts y workflows que construyen binarios a partir del código de Microsoft con una configuración de producto comunitaria. Utiliza Open VSX como registro de extensiones predeterminado.

Funciones principales

Edición de código, terminal integrada, depuración, control de versiones, workspaces y extensiones. La experiencia depende de extensiones instaladas y de la compatibilidad de cada una con la distribución.

Instalación y primera configuración

Descarga el paquete correspondiente a tu arquitectura desde las releases del proyecto. Instala extensiones desde Open VSX y revisa sus permisos y editor. Si migras desde VS Code, exporta ajustes y extensiones y comprueba qué extensiones dependen de servicios o APIs exclusivas de Microsoft.

Compatibilidad y estado de mantenimiento

Windows 10 o posterior, macOS 12 o posterior y GNU/Linux; x64 y ARM64, además de otros targets Linux publicados.

Las compilaciones estables se publican de forma continua cuando upstream actualiza VS Code.

Los requisitos detallados dependen del sistema, arquitectura y paquete descargado. Consulta la documentación de la versión elegida antes de desplegarla en varios equipos.

Licencia y distribución

Los binarios de VSCodium se publican bajo MIT; extensiones y servicios tienen licencias y términos independientes.

Seguridad, privacidad y limitaciones

No todas las extensiones del Marketplace de Visual Studio son compatibles o están autorizadas para VSCodium. Comprueba su licencia, origen y disponibilidad en Open VSX. No confundas el MIT de los binarios con la licencia de cada extensión.
