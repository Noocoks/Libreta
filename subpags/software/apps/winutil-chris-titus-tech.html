Administración y mantenimiento del sistema

WinUtil (Chris Titus Tech)

Utilidad PowerShell para instalar aplicaciones, aplicar ajustes de Windows, solucionar problemas y gestionar actualizaciones y configuraciones del sistema.

Público objetivo: Administradores y usuarios avanzados que configuran instalaciones de Windows 11.

Plataformas: Windows 11; PowerShell 5.1 o posterior y permisos de administrador para las operaciones de sistema.

Qué es y cómo funciona

WinUtil es una interfaz y conjunto de scripts PowerShell que invocan herramientas y configuraciones del sistema, administran paquetes y aplican ajustes en registro, servicios, características y políticas. No es una imagen de Windows ni una distribución modificada: opera sobre una instalación existente y sus cambios dependen de las opciones seleccionadas.

Funciones principales

Instalación/actualización de aplicaciones, ajustes del sistema, configuración de Windows Update, reparaciones, solución de problemas, exportación/importación de configuraciones y herramientas de despliegue.

Instalación y configuración

La documentación actual requiere Windows 11, PowerShell 5.1+ y elevación para cambios globales. La instrucción rápida del proyecto descarga y ejecuta el script estable mediante `irm https://christitus.com/win | iex`; por seguridad, para un entorno controlado es preferible descargar el script desde el repositorio oficial, revisar el código y fijar una versión antes de ejecutarlo. Crea un punto de restauración y aplica pocos cambios cada vez.

Compatibilidad y estado

Windows 11; PowerShell 5.1 o posterior y permisos de administrador para las operaciones de sistema.

Verificación editorial 28-11-2026. La documentación oficial consultada declara Windows 11 como sistema soportado y requiere permisos de administrador para tareas de sistema.

Seguridad, privacidad y limitaciones

No ejecutes un script remoto con privilegios de administrador sin revisar su contenido y origen. Algunas opciones pueden desactivar funciones, modificar actualizaciones o eliminar componentes; los cambios pueden ser difíciles de revertir. No se recomienda aplicar presets indiscriminadamente en equipos gestionados, de producción o de terceros sin inventario y autorización. La documentación actual declara que Windows 10 ya no está soportado por el proyecto.
