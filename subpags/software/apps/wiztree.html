Archivos, compresión y gestión documental

WizTree

Analizador de uso de almacenamiento para Windows que identifica rápidamente archivos y carpetas que ocupan más espacio mediante lectura de estructuras del sistema de archivos.

Público objetivo: Usuarios y administradores que investigan discos llenos y localizan archivos grandes o duplicados.

Plataformas: Windows; el rendimiento y la velocidad dependen del sistema de archivos y permisos.

Qué es y cómo funciona

En volúmenes NTFS, WizTree puede leer directamente la Master File Table (MFT) para construir un inventario rápido de archivos y tamaños. En otros sistemas de archivos utiliza métodos de exploración convencionales, que pueden ser más lentos. Presenta los resultados como árbol y mapa visual proporcional al tamaño.

Funciones principales

Escaneo rápido de discos, vista de árbol, Treemap, búsqueda de archivos grandes, detección de duplicados, exportación CSV y soporte para unidades de red.

Instalación y configuración

Descarga desde wize-tree.com. Selecciona el volumen y espera a que termine el escaneo. Utiliza el Treemap y File View para localizar carpetas grandes; revisa rutas y propietarios antes de borrar nada. Exporta un CSV si necesitas documentar el análisis.

Compatibilidad y estado

Windows; el rendimiento y la velocidad dependen del sistema de archivos y permisos.

Licencia y distribución

Freeware propietario gratuito para uso personal. El uso comercial requiere Supporter/Business Edition según el tamaño de la organización.

Seguridad, privacidad y limitaciones

WizTree es un analizador, no un limpiador automático. Eliminar archivos del sistema, perfiles o cachés puede afectar aplicaciones y Windows. La edición gratuita es solo para uso personal; empresas y organizaciones necesitan licencia comercial.
