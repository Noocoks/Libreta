Administración y mantenimiento del sistema

Aplicaciones reunidas por su finalidad principal y por el perfil de usuario al que se dirigen.

Aplicaciones de esta categoría

  • Wintoys — Reúne diferentes herramientas y ajustes de Windows en una única interfaz. Permite gestionar aplicaciones, servicios, privacidad, rendimiento y otras configuraciones del sistema.
  • WinUtil (Chris Titus Tech) — Herramienta avanzada para configurar Windows, instalar aplicaciones, aplicar optimizaciones, gestionar componentes y realizar tareas de mantenimiento.
  • O&O ShutUp10++ — Permite modificar diferentes opciones de privacidad de Windows, incluyendo telemetría, permisos y recopilación de información.
  • Autoruns — Herramienta de Microsoft Sysinternals que permite visualizar y administrar los programas, servicios, controladores y otros elementos que se ejecutan automáticamente al iniciar Windows.
  • System Informer — Administrador avanzado del sistema que permite inspeccionar procesos, servicios, conexiones, actividad y otros componentes internos de Windows.
  • Process Explorer (Procexp) — Alternativa avanzada al Administrador de tareas de Windows. Permite investigar procesos activos, archivos abiertos, bibliotecas utilizadas y otros detalles técnicos.
  • RAMMap — Herramienta de Microsoft Sysinternals que permite analizar cómo Windows utiliza la memoria RAM, mostrando su distribución y ocupación por categorías.
  • Revo Uninstaller — Desinstalador avanzado que permite eliminar programas y buscar archivos, carpetas y entradas del registro que pueden quedar después de una desinstalación convencional.
  • Geek Uninstaller — Desinstalador ligero que permite eliminar programas y buscar restos de instalaciones anteriores.
  • Bulk Crap Uninstaller — Desinstalador masivo que permite eliminar varios programas simultáneamente y detectar aplicaciones con instalaciones o desinstaladores poco convencionales.
  • Display Driver Uninstaller (DDU) — Herramienta especializada en eliminar completamente controladores gráficos. Resulta especialmente útil cuando se necesita realizar una instalación limpia de los drivers de una tarjeta gráfica.
  • UniGetUI — Interfaz gráfica que permite gestionar programas y paquetes mediante diferentes gestores, como WinGet, Scoop y Chocolatey, sin necesidad de utilizar constantemente la terminal.
