Archivos, compresión y gestión documental

Aplicaciones reunidas por su finalidad principal y por el perfil de usuario al que se dirigen.

Aplicaciones de esta categoría

  • WizTree — Analiza los discos duros y SSD para mostrar qué carpetas y archivos ocupan más espacio. Facilita localizar rápidamente los elementos que consumen almacenamiento.
  • QuickLook — Permite previsualizar archivos rápidamente desde el Explorador de Windows, normalmente pulsando la barra espaciadora, sin necesidad de abrir su aplicación correspondiente.
  • Bulk Rename Utility — Permite cambiar el nombre de grandes cantidades de archivos simultáneamente mediante reglas, numeración, sustituciones y filtros avanzados.
  • FreeFileSync — Herramienta para sincronizar carpetas y realizar copias de seguridad, comparando archivos y detectando modificaciones entre diferentes ubicaciones.
  • Ditto — Gestor avanzado del portapapeles que conserva un historial de textos y otros elementos copiados para poder recuperarlos y reutilizarlos posteriormente.
  • Everything — Buscador de archivos para Windows que permite localizar documentos, carpetas y otros elementos prácticamente al instante mediante la indexación de nombres.
  • Files — Explorador de archivos alternativo para Windows que incorpora pestañas, paneles, etiquetas y una interfaz moderna.
  • File Pilot — Explorador de archivos alternativo centrado en la velocidad y la productividad, con pestañas, paneles, búsqueda y diferentes opciones de personalización.
  • Recuva — Herramienta de recuperación de archivos eliminados. Permite intentar recuperar documentos, fotografías y otros datos de discos duros y unidades extraíbles.
  • 7-Zip — Compresor y descompresor de archivos que admite 7z, ZIP, TAR y otros formatos.
