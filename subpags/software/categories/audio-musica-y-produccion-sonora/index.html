Audio, música y producción sonora

Aplicaciones reunidas por su finalidad principal y por el perfil de usuario al que se dirigen.

Aplicaciones de esta categoría

  • EarTrumpet — Mejora el control de volumen de Windows y permite ajustar individualmente el nivel de sonido de cada aplicación y dispositivo de audio.
  • Peace — Interfaz gráfica para Equalizer APO que permite configurar ecualización, filtros y efectos de audio. Necesita Equalizer APO para procesar el sonido.
  • VoiceMeeter — Mezclador de audio virtual que permite combinar, enrutar y controlar diferentes entradas y salidas de sonido, tanto físicas como virtuales.
  • Spicetify — Herramienta de personalización de Spotify que permite instalar temas, extensiones y modificaciones visuales en el cliente de escritorio compatible.
  • Winamp — Reproductor multimedia clásico destinado a organizar y reproducir música, con soporte para listas de reproducción y complementos.
  • Audacity — Editor y grabador de audio multipista para grabar, limpiar, procesar y exportar sonido.
