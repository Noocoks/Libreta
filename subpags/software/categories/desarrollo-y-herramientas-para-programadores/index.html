Desarrollo y herramientas para programadores

Aplicaciones reunidas por su finalidad principal y por el perfil de usuario al que se dirigen.

Aplicaciones de esta categoría

  • Docker Desktop — Plataforma que permite crear, ejecutar y gestionar contenedores desde Windows. Facilita utilizar aplicaciones y servicios en entornos aislados, evitando tener que instalar todas sus dependencias directamente en el sistema operativo. Es especialmente útil para desarrollo web, bases de datos, servidores y entornos de pruebas.
  • Java (JDK) — Entorno de desarrollo que proporciona las herramientas necesarias para programar, compilar y ejecutar aplicaciones desarrolladas en Java. Incluye el compilador, herramientas de desarrollo y el entorno de ejecución correspondiente.
  • Apache NetBeans — Entorno de desarrollo integrado (IDE) que permite programar en diferentes lenguajes, especialmente Java. Incluye herramientas para escribir código, depurar aplicaciones y gestionar proyectos.
  • Visual Studio Code — Editor de código fuente desarrollado por Microsoft. Permite trabajar con numerosos lenguajes de programación mediante extensiones, depuración, terminal integrada y herramientas de control de versiones. Es especialmente útil para desarrollo web, Python, JavaScript, HTML, CSS y muchos otros proyectos.
  • Responsively App — Navegador especializado en desarrollo web que permite visualizar una misma página simultáneamente en diferentes resoluciones y tamaños de pantalla. Facilita comprobar cómo se comporta una página web en móviles, tablets y ordenadores sin tener que cambiar constantemente de dispositivo o ventana. Incluye perfiles de dispositivos, inspección de elementos y capturas simultáneas.
  • Notepad++ — Editor de texto y código con resaltado de sintaxis, pestañas, búsqueda y complementos.
