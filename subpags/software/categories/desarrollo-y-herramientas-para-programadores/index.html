Qué encontrarás aquí

Entornos y utilidades que acompañan el ciclo de desarrollo: escribir código, preparar runtimes, gestionar dependencias, levantar servicios y comprobar interfaces.

Dirigida a estudiantes, desarrolladores y personas que construyen o mantienen aplicaciones y sitios web.programaciónentornosdesarrollo web

Cómo está organizada

La categoría agrupa herramientas por el uso principal que les daría quien las busca. Cada entrada conduce a su propia ficha, donde se desarrolla la información de la aplicación.

APLICACIÓN 01

Docker Desktop

Plataforma que permite crear, ejecutar y gestionar contenedores desde Windows. Facilita utilizar aplicaciones y servicios en entornos aislados, evitando tener que instalar todas sus dependencias directamente en el sistema operativo. Es especialmente útil para desarrollo web, bases de datos, servidores y entornos de pruebas.

APLICACIÓN 02

Java (JDK)

Entorno de desarrollo que proporciona las herramientas necesarias para programar, compilar y ejecutar aplicaciones desarrolladas en Java. Incluye el compilador, herramientas de desarrollo y el entorno de ejecución correspondiente.

Consultar ficha técnica→

APLICACIÓN 03

Apache NetBeans

Entorno de desarrollo integrado (IDE) que permite programar en diferentes lenguajes, especialmente Java. Incluye herramientas para escribir código, depurar aplicaciones y gestionar proyectos.

Consultar ficha técnica→

APLICACIÓN 04

Visual Studio Code

Editor de código fuente desarrollado por Microsoft. Permite trabajar con numerosos lenguajes de programación mediante extensiones, depuración, terminal integrada y herramientas de control de versiones. Es especialmente útil para desarrollo web, Python, JavaScript, HTML, CSS y muchos otros proyectos.

Consultar ficha técnica→

APLICACIÓN 05

Responsively App

Navegador especializado en desarrollo web que permite visualizar una misma página simultáneamente en diferentes resoluciones y tamaños de pantalla. Facilita comprobar cómo se comporta una página web en móviles, tablets y ordenadores sin tener que cambiar constantemente de dispositivo o ventana. Incluye perfiles de dispositivos, inspección de elementos y capturas simultáneas.

APLICACIÓN 06

Notepad++

Editor de texto y código con resaltado de sintaxis, pestañas, búsqueda y complementos.
