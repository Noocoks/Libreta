Qué encontrarás aquí

Programas para gestionar descargas y preparar medios de instalación o arranque, desde imágenes ISO hasta colas de descarga.

Especialmente útil al preparar equipos, instalar sistemas operativos o gestionar descargas de forma organizada.descargasUSB arrancableinstalación

Cómo está organizada

La categoría agrupa herramientas por el uso principal que les daría quien las busca. Cada entrada conduce a su propia ficha, donde se desarrolla la información de la aplicación.

Aplicaciones de esta categoría

4 fichas disponibles · selecciona una para consultar sus detalles

APLICACIÓN 01

Rufus

Permite crear unidades USB arrancables a partir de imágenes ISO. Es especialmente útil para preparar instaladores de Windows y distribuciones Linux.

Consultar ficha técnica→

APLICACIÓN 02

Ventoy

Permite preparar un USB arrancable en el que se pueden copiar varias imágenes ISO y seleccionarlas desde un menú al iniciar el equipo.

Consultar ficha técnica→

APLICACIÓN 03

JDownloader

Gestor de descargas que automatiza la descarga de archivos desde numerosos servicios compatibles. Incluye colas, reconexión y gestión de enlaces.

Consultar ficha técnica→

APLICACIÓN 04

qBittorrent

Cliente BitTorrent gratuito y de código abierto que permite descargar y compartir archivos mediante el protocolo BitTorrent.
