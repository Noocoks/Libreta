Descargas y medios de instalación

Aplicaciones reunidas por su finalidad principal y por el perfil de usuario al que se dirigen.

Aplicaciones de esta categoría

  • Rufus — Permite crear unidades USB arrancables a partir de imágenes ISO. Es especialmente útil para preparar instaladores de Windows y distribuciones Linux.
  • Ventoy — Permite preparar un USB arrancable en el que se pueden copiar varias imágenes ISO y seleccionarlas desde un menú al iniciar el equipo.
  • JDownloader — Gestor de descargas que automatiza la descarga de archivos desde numerosos servicios compatibles. Incluye colas, reconexión y gestión de enlaces.
  • qBittorrent — Cliente BitTorrent gratuito y de código abierto que permite descargar y compartir archivos mediante el protocolo BitTorrent.
