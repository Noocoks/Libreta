Hardware, diagnóstico y periféricos

Aplicaciones reunidas por su finalidad principal y por el perfil de usuario al que se dirigen.

Aplicaciones de esta categoría

  • CrystalDiskInfo — Permite consultar el estado de salud de discos duros y SSD mediante datos S.M.A.R.T., temperatura y otros indicadores disponibles.
  • CPU-Z — Muestra información técnica del procesador, placa base, memoria RAM y otros componentes del equipo.
  • Fan Control — Permite controlar los ventiladores del equipo mediante curvas personalizadas basadas en temperaturas y sensores compatibles.
  • OpenRGB — Permite controlar la iluminación RGB de diferentes dispositivos compatibles desde una única aplicación, evitando depender necesariamente del software de cada fabricante.
