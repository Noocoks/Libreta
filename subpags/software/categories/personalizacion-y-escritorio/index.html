Personalización y escritorio

Aplicaciones reunidas por su finalidad principal y por el perfil de usuario al que se dirigen.

Aplicaciones de esta categoría

  • Nilesoft Shell — Permite personalizar el menú contextual de Windows (clic derecho), añadiendo comandos, accesos directos y submenús personalizados.
  • TranslucentTB — Permite modificar la apariencia de la barra de tareas de Windows, aplicando transparencia, desenfoque y diferentes estilos visuales.
  • Windhawk — Plataforma de modificaciones para Windows que permite instalar pequeños complementos (mods) para cambiar la apariencia y el comportamiento del sistema.
  • Lively Wallpaper — Permite utilizar fondos de pantalla animados e interactivos en Windows, incluyendo vídeos, animaciones y páginas web.
  • Wallpaper Engine — Aplicación para utilizar, descargar y crear fondos de pantalla animados e interactivos. Cuenta con una gran biblioteca de fondos creados por la comunidad.
  • Rainmeter — Permite personalizar el escritorio mediante widgets que muestran información del sistema, relojes, accesos directos, estadísticas y otros elementos visuales.
  • MyDockFinder — Añade un dock inspirado en macOS a Windows, con accesos directos, animaciones y diferentes opciones de personalización.
  • Twinkle Tray — Permite controlar el brillo de uno o varios monitores directamente desde Windows, facilitando la gestión de pantallas externas.
  • FluentFlyout — Moderniza los paneles flotantes de Windows, como los controles de volumen y multimedia, utilizando una interfaz basada en Fluent Design.
  • Winstep Nexus Dock — Dock para Windows que permite organizar accesos directos, aplicaciones y widgets en el escritorio, con opciones de personalización visual y animaciones.
  • Seelen UI — Permite transformar y personalizar diferentes elementos de la interfaz de Windows, incluyendo barras de tareas, paneles y otros componentes visuales.
  • Anima Engine — Aplicación para personalizar el escritorio de Windows mediante fondos animados, GIF, vídeos, imágenes y contenido multimedia.
