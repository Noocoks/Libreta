Productividad, organización y oficina

Aplicaciones reunidas por su finalidad principal y por el perfil de usuario al que se dirigen.

Aplicaciones de esta categoría

  • DeepL — Traductor que permite traducir textos y documentos entre diferentes idiomas, ofreciendo resultados naturales y herramientas adicionales según el plan contratado.
  • Obsidian — Aplicación de notas basada en archivos Markdown locales. Permite crear una base de conocimiento personal, relacionar notas entre sí y utilizar complementos para ampliar sus posibilidades.
  • Flow Launcher — Lanzador de aplicaciones y buscador rápido que permite abrir programas, localizar archivos y ampliar funcionalidades mediante complementos.
  • LibreOffice — Suite ofimática con procesador de textos, hojas de cálculo, presentaciones y otras herramientas.
  • AutoHotkey — Lenguaje de automatización para Windows con atajos, macros y expansores de texto.
  • PowerToys — Colección de utilidades oficiales de Microsoft que amplían las posibilidades de Windows. Incluye herramientas como FancyZones, cambio avanzado de nombres, selector de colores, gestión de ventanas y utilidades de teclado.
