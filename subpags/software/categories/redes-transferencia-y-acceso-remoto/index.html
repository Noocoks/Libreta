Redes, transferencia y acceso remoto

Aplicaciones reunidas por su finalidad principal y por el perfil de usuario al que se dirigen.

Aplicaciones de esta categoría

  • LocalSend — Permite transferir archivos entre dispositivos conectados a una misma red local, sin depender de servicios en la nube ni necesitar crear una cuenta.
  • RustDesk — Aplicación de escritorio remoto que permite acceder y controlar otros ordenadores a distancia. Puede utilizar servidores públicos o configurarse con infraestructura propia.
  • Tailscale — Crea una red privada entre diferentes dispositivos mediante WireGuard, facilitando el acceso remoto seguro a ordenadores y servicios sin necesidad de configurar manualmente una VPN tradicional.
  • scrcpy — Permite visualizar y controlar dispositivos Android desde Windows mediante USB o TCP/IP, con baja latencia y sin necesidad de instalar una aplicación en el teléfono.
  • Vysor — Permite visualizar y controlar dispositivos Android desde el ordenador. Dispone de funciones gratuitas y otras adicionales mediante planes de pago.
  • Sunshine — Servidor de transmisión de juegos y escritorio que permite enviar la imagen del ordenador a otros dispositivos, normalmente utilizando Moonlight como cliente.
  • DroidCam — Permite convertir un teléfono móvil en una webcam para Windows, utilizando una conexión Wi-Fi o USB. Es especialmente útil para videollamadas y retransmisiones.
  • LittleBigMouse — Mejora el movimiento del cursor entre varios monitores que utilizan diferentes tamaños, resoluciones o escalados DPI.
  • WinSCP — Cliente para transferir y gestionar archivos en servidores mediante SFTP, SCP, FTP, WebDAV y S3.
